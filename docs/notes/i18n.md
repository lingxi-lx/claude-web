# 界面语言：中文和英文（2026-10-15，用户要求）

用户要求：界面默认跟着这台电脑的语言（本机是英文就打开是英文），能换，尽量中英文都全；GitHub 上的页面默认英文。

## 做法

- **中文原文就是 key**：用户看得见的字写 `tr('中文 {name}', { name })`，英文放在旁边的 `en.ts`，key 就是那句中文。没有英文条目时显示中文原文，不会空。英文复数写 `{n?one:many}`。同一句中文在两处要不同的英文（比如「项目」，侧栏标题是 Projects、别处是 project）用 `trAs('中文', 'English')`。
- **核心**：`server/src/i18n/core.ts`（`tr` / `trAs` / `tIn` / `fmt` / `registerEnglish` / `dateLocale()`），web 经 `@i18n` 别名共用；`server/src/i18n/{init,boot,index}.ts` 管服务端启动时定语言；`web/src/i18n/index.ts`、`web/src/shell/i18n.ts`（手机壳）、`desktop/src/i18n.ts`（桌面壳，rootDir 限制导入不了 server，自己一份）各一份。四份英文目录：`server/src/i18n/en.ts`、`web/src/i18n/en.ts`、`web/src/shell/en.ts`、`desktop/src/en.ts`。
- **语言怎么定**：设置 `ui.language`（`auto` | `zh` | `en`，存 meta.json，`settings.set` 时服务端 `applyLanguage`）；`auto` = 这台电脑的语言（浏览器 `navigator.language`，桌面 / 服务端 `app.getLocale()` 或环境变量 `CLAUDE_WEB_SYSTEM_LANG`），**非中文一律英文**。服务端给 index.html 注入 `<meta name="cw-lang">`，页面一开始就是对的语言；页面拿不到 meta 的（手机壳、dev server）读 localStorage 里的提示 `cw.lang`。换语言 = **整页重载一次**（store 的 `reconcileLanguage`）：一个页面 / 进程里语言是固定的，不做运行时热切换，所以模块顶层的 `tr()`（常量表、catalog）也安全。
- **服务端的限制**：模块顶层求值的 `tr()` 在服务端启动时就定了，换语言后要重启服务才换（桌面版的菜单、托盘、更新弹窗同理）。请求里现算的字（错误说明、导出、配对页）立刻跟着换。设置里的提示文字没有写这一点，README 的「界面语言」写了。
- **不翻译的**：给模型看的字（skill 全文、工具描述、记忆工具的回答）、用来匹配的正则、存进库里的值；它们在 `web/src/i18n/coverage.test.ts` 的 `ALLOWED` 里，每个写明为什么。**别把别的文件加进去**——先包 `tr()`。
- **别的代码按文字匹配消息**的地方（`explain.ts` 的「原文：」/ "Original: "、forkTitle 的 `(分叉|fork)`、「文件在磁盘上已被修改」等）两种语言都要认，`coverage.test.ts` 末尾有一个测试盯着这几句的英文。

## 加或改一句界面文字

1. 代码里写 `tr('中文')`（不要拼接、不要把中文放进变量再传给 `tr`：扫描器只认字面量，动态的会让 `coverage.test.ts` 失败）。
2. `node scripts/i18n/extract.mjs --check` 看缺哪些英文；`node scripts/i18n/extract.mjs <dir>` 把缺的导成分块的工作清单，翻好后 `node scripts/i18n/merge.mjs <dir>`，或者手写 `{ "<中文>": "<English>" }` 用 `node scripts/i18n/set.mjs <file.json>` 写进对应的 `en.ts`（会检查占位符和有没有残留中文）。`get.mjs <中文…>` / `get.mjs --find <片段>` 查现有英文。`lint.mjs` 查空格、大小写、全角标点。
3. 英文**术语统一**：对话 = conversation（不写 session），供应商 = provider（设置页标题是 Providers），中转 = relay，子代理 = subagent，网管 = the admin。先 `get.mjs --find` 看别处怎么叫的。
4. 跑 `npm test`：`coverage.test.ts` 查每个 `tr()` 都有英文、占位符一致、英文里没有中文、没有包在 `tr()` 外的中文。

## 检查

- `npm test`（上面的覆盖测试）；`node scripts/ui-smoke.cjs`（中文；它把语言固定成 zh，正则同时认 `tr('…')`）。
- **`node scripts/i18n-smoke.cjs [--shots]`**：用 `scripts/lib/demo.cjs` 的演示环境起一个英文的服务，Electron 里走一遍欢迎页和所有菜单、对话和右侧面板、每个设置页和标签、自动化 / 扩展 / 后台 / 总览、命令面板、等权限的对话、手机布局，凡是用户看得见的文字（文本、title、aria-label、placeholder、option）里还有中文，或者 console 有错误，就失败。`--shots` 保留每一步的截图。
- 真机验证用临时 HOME：`CLAUDE_WEB_SYSTEM_LANG=en-US` 起服务就是「英文电脑」。

`node scripts/readme-shots.cjs --lang en|zh [--only chat,home,…] [--out dir]` 从真实的应用拍：演示数据来自 `scripts/lib/demo.cjs`（`C:/work` 下几个小仓库，其中一个有真实的未提交改动；Claude Code 自己的 transcript 格式写成的已完成对话；假的 Anthropic 上游，一个对话在等权限、一个永远不结束），Electron 离屏截图（锁屏也能拍），网吧的 GIF 是 96 帧用 ffmpeg 合成（需要装 ffmpeg）。输出到 `docs/images/<lang>/`；`character-made.png` 与语言无关，放在 `docs/images/` 下。改了界面要重拍。`scripts/demo-up.cjs` 只起演示环境让你自己在浏览器里看。

- 网吧那张要放大：不能用 `sendInputEvent` 的滚轮（页面会跟着滚），直接在 `canvas.cafe-canvas` 上派发 `WheelEvent`。
- 演示的路径用 `C:/work`（短、中性）；不能在 bash 里写 `'C:\work'`（反斜杠被吃掉）。`mkRepo` 先清掉上一次被打断留下的目录。
- 拍之前要 `unset CLAUDE_WEB_DIST`（本机的桌面版旧页面）和中转的环境变量，否则服务起的是旧界面。

## 踩过的坑

- **英文输入框那一行放不下**：输入框一行靠容器查询（`.composer-bar.cb`）收缩，英文词长，断点要更大：英文时 ≤700px 就进窄模式，整行收缩规则从 701px 起（中文 561px 起）；英文标签也缩短了（「每步询问」→ "Ask first"，「自动改文件」→ "Accept edits"）。
- **机器翻译式的英文**：有些中文是「半句」（拼在别的字后面），英文要整句重写；`terms.ts` 的 `emptyText` 是两句式 + `inSentence`。
- **codemod 误伤**：第一次批量包 `tr()` 时把给模型看的字和数据文件也包了，测试全坏，回退后用跳过名单重跑。数据文件留在 `ALLOWED`。
- 桌面版闪屏的 HTML 里的中文不能被 codemod 碰（它是模板字符串，手工包）。
