# 后台 · 网吧（2026-10-13）

用户要求（2026-10-13）：后台的可视化换成 Mavis 那种「能到处走的办公室」，但场景是**网吧**：等距像素、网吧灯光，
子代理会走动、吃东西、打游戏；默认角色是 Claude 的小章鱼，有工位有名字；有网管，每个座位有价钱和 token，用完到前台结账；
能在右侧面板里看；另外要一个像 Codex pet 那样的「自定义角色」skill（照片或口述）。三块一起做。

brainstorm 时定下的（按顺序）：画风 = 等距像素 + 有光影（「精致像素」）；视角 = 等距斜 45°（立体房间）；
动作 = 干活时一定在座位上，空下来随机去吃喝玩（不一定代表真实状态）；座位显示 = 网费计时 + 悬停看真实 token 和估算费用；
三块一起做；自定义角色 = 角色库 + 按身份指定；实现 = 自写 Canvas 2D 引擎，像素画存成数据。

草图：`.superpowers/brainstorm/419-1791863714/content/cafe-layout.html`（不入库）。

## 1. 场景

一间等距（2:1）的网吧，房间永远是夜里（外框跟主题走，房间不跟）。区域：

| 区域 | 位置 | 内容 |
| --- | --- | --- |
| 门口 + 前台 | 左前 | 门、前台（吊灯）、收银机、网管站位、门口排队点、招牌「空位充足 / 客满」 |
| 充电宝柜 | 前台旁 | 一排闪灯的格子，客人路过借一个 |
| 零食区 | 左墙 | 发光冰柜、泡面货架、高脚桌 |
| 上机区 | 中间 | 一排排座位：桌、显示器、RGB 键盘、红色电竞椅、头顶座位牌（编号 + 网费） |
| 包间 | 右后，玻璃隔开 | 后台命令的机器（没人坐，自己闪灯） |
| 吸烟区 | 右前，玻璃阳台 | 排风扇、一点烟雾 |
| 厕所 | 后角 | 门上「有人 / 无人」灯 |
| 墙上 | | 霓虹招牌「CLAUDE 网咖」、霓虹灯带、大屏（主对话这一轮在干什么）、窗外夜景（偶尔车灯划过） |

座位：工作流的每个阶段一排（标题写在排头），「子代理」一排（单个子代理任务），每排最多 8 个，最多 8 排；
房间按排数变长（地图是快照的纯函数）。超过 64 个座位：门口排队，立牌「还有 N 位在排队」。

灯光：场景画完后整体压暗（multiply），再用 `lighter` 叠发光源：屏幕（干活青光、打游戏橙红光、蓝屏蓝光）、霓虹灯带
（偶尔闪）、冰柜、前台吊灯、包间机器、窗外。

## 2. 角色和行为

- **网管** = 主对话。主对话这一轮在跑：在前台敲电脑；空闲：擦桌子、巡场、给冰柜补货（随机）。点网管 = 回到主对话。
- **客人** = 每个子代理（`BgAgent`）。头顶名字（`label`）。默认小章鱼，颜色 = `--agent-<color>`。
- **机器** = 后台命令（`kind: 'shell'`），在包间。

客人状态机（`sim.ts`，每个客人一个 actor）：

1. `arrive`：从门口出现 → 走到前台 → 气泡「欢迎光临，07 号机」（网管说）。
2. `toSeat` → `seated`：走到分到的座位坐下，网费从 `startedAt` 起算。
3. `work`（`state === 'running'` 且最近 20 秒内有 `beats`，或刚开始）：坐着敲键盘，屏幕滚代码；`lastSummary` 变化时头顶冒 3 秒气泡。
4. `idle`（`queued`、`done` 但任务还在跑、或 `running` 却 20 秒没动静）：随机挑一个活动——吃泡面 / 喝饮料（零食区）、
   打游戏（回座位，屏幕换射击画面）、上厕所、吸烟区、借充电宝、跟邻座聊天（两人冒「…」）、发呆——每个 5–20 秒，做完再挑。
5. 一有活（进入 `work` 的条件成立）：放下手里的事走回座位。
6. `checkout`：任务 / 自己结束（`done`、`failed`、`stopped`，或任务结束）→ 走到前台 → 收银机「叮」+ 硬币 → 头顶小票
   （名字、座位、上机时长、网费、token、估算费用）→ 走出门消失。小票同时进「今日账单」。
   - `failed`：先蓝屏、挠头，小票红字「异常下机」；`stopped`：网管走过去拍肩，小票「被叫下机」。
7. 快照里消失 / 断线：原地等，不结账（下一份快照到了再说）；30 秒后仍没有才算离开（直接淡出，不结账）。

座位分配：按任务 + 阶段 + agent 的出现顺序，稳定（同一个 agent 一直是同一个座位）。

网管随机喊话：「07 号机还有 5 分钟」「谁的泡面没扔」「欢迎光临」。声音（结账「叮」）默认关，`cafe.sound` 打开。

交互：点客人 → 现在的 `AgentDrawer`；悬停座位牌 → tooltip（真实 token、估算费用、用时、最近一步）；点机器 → 那条命令
（`AgentDrawer` 的命令视图，停止）；拖动平移、滚轮缩放、双击回全景；键盘：Tab 在客人之间切换（画布上方一层透明按钮，
屏幕阅读器读「researcher · 在跑 · 07 号机」）。

## 3. 数据、位置、代码

- 数据只来自现有的 `background.changed` 快照（`BgSession`），**不加服务端协议**（角色除外，见 §4）。
- 网费：`cafe.rate`（元 / 小时，默认 5），按上机时长。纯娱乐。
- 估算费用：`tokens × 模型输入单价`，标「约」；只有 Claude 模型（`@catalog` 的价格表，没有就「费用未知」）；tooltip 写明
  「只按输入单价估，实际会更高」。
- 今日账单：快照里已结束的任务的客人，按结束时间倒序。
- 位置：
  - 「后台」页：`Office` 换成网吧（主体），右列：今日账单 · 在场的人（`AgentCards`）· 动态（`EventFeed`）；关系图保留成切换。
  - 右侧面板：`PANELS` 加 `cafe`（tier `extra`，名字「网吧」，图标栏 ··· 也有），缩小版，跟着当前对话。
  - 手机：页面全屏，拖动 / 双指缩放。
- 代码 `web/src/features/cafe/`：
  - `sprites/`：像素画数据（调色板 + 格子），`bake.ts` 把它们画成离屏画布并缓存（按 id + 朝向 + 帧）。
  - `iso.ts`：等距换算；`map.ts`：快照 → 地图（区域、座位、可走格、兴趣点）纯函数；`path.ts`：A*。
  - `sim.ts`：`step(world, snapshot, now, rng)` 纯函数，actor 状态机；`rng` 带种子。
  - `render.ts`：画房间、按深度排序画物体和人、灯光层、气泡、小票。
  - `Cafe.tsx`：画布 + 透明按钮层 + tooltip + 小票浮层；页面和面板共用。只在看得见时跑（`IntersectionObserver` +
    `hidden` + 页面可见），最多 30 帧 / 秒。
  - 减少动画：不走路（直接到位）、霓虹不闪、气泡不动。
- 删掉 `Office.tsx`、`office-layout.ts`（及其测试）；`Character.tsx`（SVG 头像）保留给卡片和抽屉。

## 4. 角色格式和 skill

角色 JSON（`<dataDir>/characters/<id>.json`；内置的在代码里）：

```json
{ "v": 1, "id": "cat-mimi", "name": "咪咪",
  "palette": { "k": "#1b1b1b", "o": "#e8a33c", "w": "#ffffff" },
  "front": ["……24 行，每行 24 个字符，调色板字母或 . ……"],
  "back":  ["……"],
  "rig": { "legs": 19, "eyes": [[8,9],[15,9]], "hands": [[4,15],[19,15]] },
  "draft": true }
```

校验：`id` `[a-z0-9-]{1,40}`；`name` ≤ 16 字；调色板 1–16 色、字母单字符、颜色 `#rrggbb`；front / back 正好 24×24 且只用调色板里的字母；
`legs` 在 12–23；眼睛 / 手的坐标在格子里、眼睛那一格不是透明。

引擎动作（对两张图做变换）：朝向 = front（朝前两个斜向，一个镜像）/ back（朝后两个斜向）；走路 4 帧 = `legs` 以下的行左右半边交替上下
1 格 + 身体起伏；坐 = `legs` 以下藏在椅背后；敲键盘 / 打游戏 = 手的位置叠 2×2 的手 + 抖动（打游戏更快）；吃 = 手位叠碗 + 点头；
眨眼 = 眼睛那格换成相邻的皮肤色（调色板里离它最近的非透明色）。

服务端 `server/src/characters/`：

- `CharacterService`：`list / get / saveDraft / save / remove / assign`，文件读写（tmp + rename），坏文件跳过并记日志。
- 请求 `characters.list / save / delete / assign`，事件 `characters.changed`；远程（`cwRemote`）连接只读；联邦 LOCAL。
- 指定 `cafe.assign`（meta.json settings）：`{ admin?, default?, byType: {Explore: id}, byName: {researcher: id} }`，
  匹配 名字 > 类型 > 默认 > 小章鱼。
- `preview.ts`：把角色渲染成 PNG（正面、背面、走路 4 帧，8 倍放大，纯 JS PNG 编码，zlib），给模型看。

MCP 服务器 `cafe`（`server/src/characters/mcp.ts`，接入同 `web`：Claude 的 `mcpServers`、ACP、Codex `-c`；回连
`POST /api/cafe/tool`，回环 + 文件密钥）：

- `character_guide()`：返回 skill 的说明全文。
- `character_draft(character)`：校验；不合法回错误列表；合法则存草稿、返回预览 PNG + 一句话。
- `character_save(id)`：草稿转正。
- `character_assign(id, target)`：`target` = `admin | default | type:<名> | name:<名>`；走权限确认（不预先放行）。
- `character_list()`。

skill `cafe-character`（`server/assets/plugins/cafe/skills/cafe-character/SKILL.md`）：格式、像素画规矩（深色轮廓、≤ 16 色、头大身小、
眼睛 ≥ 2 格、24×24 里留 1 格边）、照片里提取什么（发型 / 发色 / 眼镜 / 衣服主色 / 标志物）、流程（草稿 → 给用户看 → 改 → 保存 → 问要不要指定）。
Claude 对话经 SDK `plugins: [{type:'local', path}]` 带进去；运行内核不认时（实现第一步验证），只靠 `character_guide`。

界面：网吧右上角「角色库」：所有角色（含草稿）动着的预览、指定给谁、删除；「捏个角色」= 新对话 + 输入框预填
「用 cafe-character 帮我做一个角色：」。

## 5. 出错与测试

- 坏角色文件跳过；指定的角色没了 → 默认；拿不到 2D 画布 → 只显示卡片和动态；不发后台数据的 agent → 只有网管、「店里没人」。
- 单测：`map`、`path`、`sim`（种子随机 + 快照序列：进门 → 前台 → 座位 → 空闲活动 → 回座 → 结账 → 出门；失败 / 停止 / 断线）、
  角色校验与动作变换、网费与估算、服务端预览 PNG、指定匹配。
- e2e `server/ws-phase26.mjs`（默认列表）：MCP 协议驱动 `cafe`：不合法草稿退回、合法返回 PNG、草稿出现在 `characters.list`、
  保存、指定（权限）、`characters.changed`、远程连接不能改。
- ui-smoke「cafe」：注入快照、画布非空、点角色开抽屉、悬停座位牌、右侧面板打开网吧、减少动画、手机宽度、无 console 错误。
- 截图自查：各区域、空店、客满、结账、蓝屏、浅色 / 深色外框。
- 真机：官方二进制跑小工作流；中转 Key 真跑一次 skill（照片 → 草稿 → 改一轮 → 保存 → 指定给 Explore）。
