# 照官方桌面版录屏改界面（2026-10-16，第 6 期）

## 背景

用户给了一段 53 秒的录屏（官方 Claude 桌面版 Code 页，Windows，暗色，一个正在跑 `npm run build` 的对话），要求「直接借鉴 UI 和 UX 来用」。逐帧观察记录见下面「观察」一节（原始笔记在执行时的临时目录）。只照着看到的界面和交互自己实现，不碰官方安装包。

## 观察（录屏里是什么样）

**布局**：左侧栏 | 对话（内容列 ~800px 居中）| 右侧「信息栏」（~290px，卡片堆叠）。点标题栏的终端 / 浏览器 / 文件图标，工具面板开在**信息栏的右边**，三栏并排：对话 | 信息栏 | 工具面板；对话列跟着变窄。

**标题栏右侧一排图标**：信息栏、终端、审阅（diff）、浏览器、文件、⋮；当前开着的那个图标有浅底。⋮ 菜单：旁聊 `Ctrl+;`、后台任务（数字）、「保持电脑唤醒 · 只对这个对话」开关。

**信息栏的卡片**（每张圆角发丝边，可折叠，hover 右上角出拖拽柄，可拖动排序）：
1. 环境：机器名、文件夹（+ 位置）、分支、「远程控制」开关。
2. 上下文：折叠时「13%」+ 小进度条；展开是 `/context` 的明细——「13% used · 89k / 700k」+ 多色分段条 + 每类一行（彩色方块、名称、token、百分比：Messages、System tools、MCP tools、Skills、System prompt、MCP server instructions、Memory files、Custom agents、Since last update、Autocompact buffer、Free space，灰色的 deferred 行），可展开的 MCP tools / Memory files / Custom agents 清单，底注「3 分钟前更新，这一轮结束时刷新」。
3. 连接器：「12 个要重连」。
4. 改动：`+230 −22` + 「建 PR」。
5. 后台任务：每个命令一行（终端图标、命令、实时秒数、停止方块）。

**对话里**：
- 运行行：Claude 花形图标（在跑时变形动画）+「Opus 5.5 · Running npm run build 26s ⌄」灰字；展开是一个描边框，每步一行「Ran a command ›」「Running npm run build… ›」，行间细线。
- 计划卡：描边圆角，每行一个状态圈（进行中 = 转动的弧，待办 = 虚线圆）+ 文本，没有标题。
- 用户消息右对齐深灰圆角气泡；助手正文无气泡。
- 鼠标经过助手消息，下面出一行：复制、分叉、钉住、朗读、「2 分钟前」。

**输入区**：
- 输入框上方一块：用户在 Claude Code 设置里配的 **statusLine** 命令的输出（多行、带颜色）。
- 输入框：一行高，左「+」，占位「Enter to send, Ctrl+Enter to queue for later」，右边录屏、麦克风。
- **框外下面一行**：左边权限模式纯文字（「Bypass permissions」），右边「Opus 5.5 High」（模型 + 灰色强度）和上下文小环。
- 「+」菜单：添加文件或图片 `Ctrl+U`、添加文件夹、斜杠命令、连接器 ›（浏览 / 管理 / 每个连接器在本对话的开关）、插件 ›。
- 模型菜单：前四个模型带数字 1–4、强度 ›、更多模型 ›、「快速模式」开关。

**风格**：只有两档文字（白 / 灰），颜色只用于 diff、开关、行内代码、Claude 图标；图标 16px 线性；按钮无边框 hover 才有底；文案很短。

## 和 claude-web 现在的差别（用户截图）

我们是：标题行（标题 + 文件夹 chip + `+N −M` + 图标）、右侧面板一次只开一个标签（审阅 / 文件 / 终端 / 浏览器 / 任务 / 总览…）、输入框里一排 chip（模型、子代理、深入、完全放开、麦克风、发送）、运行时一行「已处理 5 分 57 秒 · 读了 23 个文件…」+ RunCard。没有：按对话的信息栏、上下文明细、statusLine、排队发送、连接器的对话内开关、快速模式开关、数字选模型、消息的分叉 / 时间、保持唤醒的对话级开关、浏览器空状态的预览服务器列表。

## 要做的（按顺序）

### 1. 信息栏（`features/info/`）
- 每个对话自己的一栏，放在对话列右边（在对话标签页里，不是全局右侧面板）。宽 288px；面板宽度不够（对话列 < 560px）时自动收起。开关：标题栏信息栏图标，设置 `ui.infoPanel`（默认开），meta.json。
- 卡片：环境（机器 = 本机名 / 联邦 peer 名、文件夹、分支、手机远程开关 = 已有的远程监听开关的状态和入口）、上下文（见下）、连接器（`info.mcpServers` 里 failed / needs-auth 的个数 →「N 个要重连」，展开列出每个和状态，点「管理」去扩展页连接器）、改动（会话的 `+N −M`，「审阅」打开审阅面板，「建 PR」用已有的建 PR 流程；有 PR 时显示 PR 号和状态）、后台任务（这个对话的后台命令 / 子代理，实时秒数，停止）。
- 折叠状态和顺序存 `ui.infoCards`（`{ order: string[], collapsed: string[] }`）；卡片标题行可拖动排序（原生 drag，键盘：标题行聚焦时 Alt+↑/↓ 移动）。
- 上下文卡展开时调 `session.contextUsage { detail: 'full' }`（已有），一轮结束时自动刷新；没在跑的对话显示上次的或「开着的对话才有明细」。分类颜色用 SDK 给的 `color`（主题色名 → 我们的令牌映射，未知的用灰），按 `kind` 分组：used / free / buffer / deferred。

### 2. 标题栏工具图标
- 对话标题行右侧换成一排：信息栏、终端、审阅、浏览器、文件、⋮。终端 / 审阅 / 浏览器 / 文件就是打开右侧面板的对应标签（再点一次关掉），当前开着的那个图标有浅底。原来的 `+N −M` 挪进信息栏的改动卡（信息栏关着时仍在标题行显示）。
- ⋮ 菜单加：旁聊（`Ctrl+;`）、后台任务（数字）、「保持电脑唤醒（只对这个对话）」开关——桌面版用已有的 keep-awake，加一个按对话的来源（对话在跑时阻止睡眠）。

### 3. 输入区
- 权限、模型 + 强度、上下文小环从框里挪到**框下面一行**：左权限（纯文字 + 小箭头），右「模型 强度」+ 小环。框里只剩 +、文字、（子代理 / 深入等能力标签照旧在附件行）、麦克风、发送。
- 占位：「Enter 发送，Ctrl+Enter 排到这一轮之后」。**排队**：对话在跑时按 Ctrl+Enter，消息进这个对话的待发队列（输入框上方一行「排队中：…  ×」），这一轮结束自动发出；Enter 照旧是插话。
- **statusLine**：用户在 `~/.claude/settings.json`（及项目设置）里配了 `statusLine: { type: 'command', command, padding? }` 时，服务端按 Claude Code 的约定跑它（stdin 是 JSON：session_id、transcript_path、cwd、model {id, display_name}、workspace {current_dir, project_dir}、version、output_style、cost），每轮结束 / 打开对话 / 每 10 秒（在跑时）刷新，最长 5 秒超时，输出截 20 行；前端把 ANSI 颜色转成 span 显示在输入框上方。没配就不显示。设置里一个开关「显示 statusLine」（默认开）。

### 4. 模型菜单
- 前四个模型右侧显示 1–4，菜单开着时按数字直接选（第 5 期的数字键已经做了，这里只是显示数字）。
- 「强度 ›」子菜单（就是现在强度 chip 的内容），「更多模型 ›」子菜单（其余模型），「快速模式」开关（`q.applyFlagSettings({ fastMode })`，只在 Claude 引擎、模型支持时可用；新请求 `session.fastMode`）。

### 5. + 菜单
- 加「斜杠命令」（在框里放一个 `/` 打开补全）、「连接器 ›」子菜单：管理连接器（去扩展页）+ 这个对话里每个 MCP 服务器一个开关（`q.toggleMcpServer(name, on)`，新请求 `session.toggleMcp`）。添加文件快捷键 `Ctrl+U`。

### 6. 对话里
- 运行行：「✳ 模型 · 正在 <当前步骤> 26s ›」，Claude 花形图标在跑时循环变形；展开的步骤框是描边圆角、行间细线，每步「跑了一条命令 ›」这类短句。
- 计划（TodoWrite）卡：描边圆角，进行中 = 转动的弧、待办 = 虚线圆、完成 = 勾 + 灰字删除线，没有标题行。
- 助手消息 hover 操作加：分叉（从这条开始新对话，已有 fork）、时间（「2 分钟前」）。

### 7. 面板空状态
- 浏览器标签的空白页：列出项目 `.claude/launch.json` 的配置（名字、端口、▶ 启动），「查看全部」，底注「运行一个服务器来预览，或者输入网址。这个列表在 .claude/launch.json 里改」。新请求 `preview.list { cwd }`、`preview.start { cwd, name }`（用第 5 期的 PreviewService）。
- 文件面板没打开文件时：「打开的文件会显示在这里 · 在文件树里选，或者点对话里的文件路径」。

## 实现时改了的（2026-10-16）
- 输入框：在跑时仍是 Enter 排队（测试和停靠的权限卡都靠它），加的是 Ctrl+Enter = 插话；占位字照这个写。
- 模型菜单的「更多模型 ›」不做：列表本来全列、能搜。快速模式只在 CLI 报了 `fast_mode_state`、又不是中转时出现。
- 文件面板的空状态不做：打开的文件是窗格里的标签，不在面板里。
- statusLine 只读用户级 `~/.claude/settings.json`，项目里的不读（别人仓库的命令不能一打开就跑）。

## 不做
- 「对话 / 代码」切换（我们有「只聊天」）、☰ 应用菜单、前进后退（我们的标题栏已经有别的布局）、录屏按钮、朗读、钉住。
