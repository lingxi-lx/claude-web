# 官网（二）：会动的网吧首屏 + 视觉翻新 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把官网首屏换成产品自己的等距像素网吧（分层视差、60 秒演示日、跟着章节推镜头、可玩的叠层卡片和微交互），并把整站从「一种颜色、没有动画」翻新成霓虹像素风。

**Architecture:** 官网通过 Vite 别名直接复用产品的网吧引擎（`iso / map / path / sim / bake / render / money`），产品行为不变，只把 `render()` 的身体拆成几个导出函数。引擎里的 `tr()` 被别名指到官网的垫片，英文来自一个构建时生成的小表。`site/src/hero/` 里是纯函数（演示日、章节镜头、分级、视差、Konami）加一个分层 Canvas 渲染器和一个 T0 才有的 WebGL 后处理；场景 JS 懒加载，首屏先显示用 Electron 截出来的海报。

**Tech Stack:** Astro 7.4.1、Vitest 4、TypeScript 7、Node 22.22（类型擦除跑 `.ts` 脚本）、Canvas 2D、WebGL2、WebAudio、subset-font 2.9.0（构建期）、Electron（仓库自带，截海报 / 冒烟）、ffmpeg。

设计文档：`docs/superpowers/specs/2026-10-21-website-design.md`（§4、§5、§7、§8、§9）。第一份计划：`docs/superpowers/plans/2026-10-22-site-1-skeleton.md`；官网笔记：`docs/notes/site.md`。第三份（主题放映厅）不在这里。

这一份**不做**：§4.4 镜头推近时屏幕换成真文字（屏幕仍是色条）、§4.2 滚动中 0–6% 的推拉（`--hero-progress`）、§5 的「悬停 PC 抬亮」和泡面吸溜声、§5.1–5.2 放映厅、Lighthouse 和集显帧率的人工验收。时间线前的过程动画用一个 CSS 小方块动画代替产品的 `ProcessGlyph`（那个依赖产品主题系统）。

- [ ] **Step 2: 写 `web/src/features/cafe/render.test.ts`（只有第一个测试：记下拆之前的画法）**

这个测试用一个记录调用的假 Canvas 画一帧，把所有调用串起来算哈希存成快照。拆完之后同一帧必须得到同一个快照——这就是「像素不变」的证据（节点环境里没有真 Canvas）。

```ts
// render() before and after the split (the site draws the same room in layers): a recording fake canvas logs every
// call of one frame; the log's hash is a snapshot, so the product's picture cannot change without this failing.
import { beforeAll, describe, expect, it } from 'vitest';
import type { BgSession } from '@shared';
import { ADMIN, BUILTIN, OCTOPUS } from '@characters';
import { createWorld, step, type World } from './sim';
import * as R from './render';

const log: string[] = [];
let ids = 0;
const fmt = (v: unknown): string => (typeof v === 'number' ? String(Math.round(v * 1000) / 1000) : typeof v === 'string' || typeof v === 'boolean' ? String(v) : 'obj');

function fakeCanvas(): any {
  const id = ids++;
  const canvas: any = { width: 0, height: 0 };
  const ctx = new Proxy({} as Record<string | symbol, unknown>, {
    get(t, k) {
      if (k in t) return t[k];
      if (k === 'canvas') return canvas;
      if (k === 'createImageData') return (w: number, h: number) => ({ width: w, height: h, data: new Uint8ClampedArray(w * h * 4) });
      if (k === 'measureText') return (s: string) => ({ width: s.length * 6 });
      if (k === 'createRadialGradient' || k === 'createLinearGradient') {
        return (...a: unknown[]) => {
          log.push(`${id}.${String(k)}(${a.map(fmt).join(',')})`);
          return { addColorStop: (o: number, col: string) => log.push(`grad(${o},${col})`) };
        };
      }
      return (...a: unknown[]) => { log.push(`${id}.${String(k)}(${a.map(fmt).join(',')})`); };
    },
    set(t, k, v) { t[k] = v; log.push(`${id}.${String(k)}=${fmt(v)}`); return true; },
  });
  canvas.getContext = () => ctx;
  return canvas;
}

function fnv(s: string): string {
  let h = 2166136261;
  for (let i = 0; i < s.length; i++) h = Math.imul(h ^ s.charCodeAt(i), 16777619);
  return (h >>> 0).toString(16);
}

const T0 = 1_800_000_000_000;
const COLORS = ['#a3e635', '#fbbf24', '#2dd4bf', '#f472b6', '#60a5fa', '#a78bfa', '#fb923c', '#22d3ee', '#e879f9', '#4ade80'];
const sess = (t: number): BgSession => ({
  sessionId: 's', updatedAt: T0, events: [], tasks: [
    { id: 'a', kind: 'agent', description: 'api', status: 'running', startedAt: T0, agents: [{ key: 'a', color: 1, label: 'api', state: 'running', startedAt: T0, beats: [t - 500] }] },
    { id: 'b', kind: 'agent', description: 'tests', status: 'running', startedAt: T0 + 1, agents: [{ key: 'b', color: 2, label: 'tests', state: 'running', startedAt: T0 + 1, beats: [t - 500] }] },
  ],
});
function world(): World {
  let w = createWorld(3, T0 - 1000);
  for (let t = T0; t <= T0 + 15_000; t += 100) w = step(w, sess(t), t, { rate: 5, mainBusy: true, reduced: false });
  return w;
}
const look = (w: World): R.Look => ({
  now: w.t, agentColors: COLORS, chars: new Map(BUILTIN.map((c) => [c.id, c])), rate: 5, session: sess(w.t), still: false, mainBusy: true, title: 'demo',
  who: (x) => (x.key === 'admin' ? ADMIN.id : OCTOPUS.id),
});

beforeAll(() => {
  (globalThis as any).document = { createElement: () => fakeCanvas() };
});

describe('render', () => {
  it('draws the same frame as before the split', () => {
    const w = world();
    const page = fakeCanvas();
    log.length = 0;
    R.render(page.getContext('2d'), 1280, 800, w, R.fitView(w, 1280, 800), look(w));
    expect({ calls: log.length, hash: fnv(log.join('\n')) }).toMatchSnapshot();
  });
});
```

```ts
export type SceneSize = { w: number; h: number; ox: number; oy: number };
export type ItemKind = 'furniture' | 'desk' | 'chair' | 'chairBack' | 'machine' | 'queue' | 'actor' | 'admin' | 'glass';
/** One standing thing of the room, in drawing order (back to front by `d`). */
export interface ItemTag { d: number; kind: ItemKind; u: number; v: number; key?: string }
interface Item extends ItemTag { draw: () => void }

/** The neon strip flickers for a moment every 13 s. */
const flickering = (look: Look) => !look.still && ((look.now / 1000) % 13) > 12.6;

/** The room itself: background, walls (window, big screen, neon, sign, posters), the floor and the door mat. */
export function drawRoom(c: Ctx, w: World, sz: SceneSize, look: Look) {
  const m = w.map;
  const o: [number, number] = [sz.ox, sz.oy];
  const now = look.now;
  c.globalCompositeOperation = 'source-over';
  c.fillStyle = '#0c0b10';
  c.fillRect(0, 0, sz.w, sz.h);

  // ---- walls ----
  onUWall(c, o, 0, m.cols, 0, WALL, P.wallU);
  onVWall(c, o, 0, m.rows, 0, WALL, P.wallV);
  onUWall(c, o, 0, m.cols, 0, 3, P.base);
  onVWall(c, o, 0, m.rows, 0, 3, P.base);
  // the window: the city at night, a car's lights now and then
  const [wu0, wu1] = m.wall.window, [su0, su1] = m.wall.screen;
  onUWall(c, o, wu0, wu1, 14, 42, '#0a1328');
  for (let i = 0; i < 26; i++) {
    const r = hash(`win${i}`);
    const u = wu0 + 0.3 + ((r % 1000) / 1000) * (wu1 - wu0 - 0.6), h = 16 + ((r >> 10) % 24);
    const on = look.still || ((now / 1000 + (r % 50)) % 9) > 1.5;
    if (on) onUWall(c, o, u, u + 0.12, h, h + 1, (r & 1) ? '#ffd46a' : '#7fd8ff');
  }
  onUWall(c, o, (wu0 + wu1) / 2 - 0.1, (wu0 + wu1) / 2 + 0.1, 14, 42, '#1c1a24');
  if (!look.still) {
    const t = (now / 6000) % 1;
    if (t < 0.35) onUWall(c, o, wu0 + (t / 0.35) * (wu1 - wu0 - 0.6), wu0 + 0.6 + (t / 0.35) * (wu1 - wu0 - 0.6), 17, 18, '#fff3c0');
  }
  // the big screen: the main conversation
  onUWall(c, o, su0, su1, 18, 40, '#0a0d14');
  onUWall(c, o, su0 + 0.3, su1 - 0.3, 20, 38, look.mainBusy ? '#0f3640' : '#14202a');
  if (look.mainBusy) for (let i = 0; i < 5; i++) {
    const len = 1 + ((hash(`bs${i}`) + Math.floor(now / 400)) % 5);
    onUWall(c, o, su0 + 0.8, su0 + 0.8 + len, 34 - i * 3, 35 - i * 3, '#4fe0c0');
  }
  // neon strips and the sign
  const flick = flickering(look);
  onUWall(c, o, 1, m.cols - 1, 48, 49.5, flick ? '#5a2048' : '#ff3cbe');
  onVWall(c, o, 1, m.rows - 1, 48, 49.5, '#3cdcff');
  // the sign: lettering lying on the back-right wall (the wall rises 1 px for every 2 along u)
  {
    const [sx, sy] = pt(o[0], o[1], 2.4, 0, 30);
    c.save();

/** What stands in the room, back to front (u + v); only what `pick` keeps when it is given (the site's layers). */
export function drawItems(c: Ctx, w: World, sz: SceneSize, look: Look, pick?: (it: ItemTag) => boolean) {
  const m = w.map;
  const o: [number, number] = [sz.ox, sz.oy];
  const now = look.now;
  const items: Item[] = [];
  const add = (tag: ItemTag, draw: () => void) => items.push({ ...tag, draw });
  for (const f of m.furniture) add({ d: f.u + (f.w ?? 1) + f.v + (f.d ?? 1) - 1, kind: 'furniture', u: f.u, v: f.v, key: f.kind }, () => drawFurniture(c, o, f, w, now, look));
  for (const s of m.seats) {
    const a = s.key ? w.actors.find((x) => x.key === s.key) : undefined;
    add({ d: s.u + s.v + 1.4, kind: 'desk', u: s.u, v: s.v }, () => drawDesk(c, o, s, a, now, look));
    // the gaming chair: its seat under whoever sits there, its back (on the viewer's side) over them
    add({ d: s.chair.u + s.chair.v + 0.4, kind: 'chair', u: s.chair.u, v: s.chair.v }, () => box(c, o, s.chair.u + 0.25, s.chair.v + 0.2, 0.55, 0.55, 4, P.chairTop, P.chairL, P.chairR));
    add({ d: s.chair.u + s.chair.v + 0.95, kind: 'chairBack', u: s.chair.u, v: s.chair.v }, () => {
      box(c, o, s.chair.u + 0.25, s.chair.v + 0.72, 0.55, 0.12, 9, '#d8404f', P.chairL, P.chairR, 4);
      box(c, o, s.chair.u + 0.4, s.chair.v + 0.7, 0.25, 0.14, 2, '#f2f2f2', '#d0d0d0', '#e0e0e0', 9.5);
    });
  }
  // the counter's till and the admin's desk lamp are part of the counter (furniture)
  for (const mc of m.machines) {
    const t = look.session?.tasks.find((x) => x.id === mc.taskId);
    add({ d: mc.u + mc.v + 1, kind: 'machine', u: mc.u, v: mc.v, key: mc.taskId }, () => drawMachine(c, o, mc.u, mc.v, t?.status === 'running', now, look));
  }
  // the overflow queue: the guests who found no seat, standing at the door
  for (let i = 0; i < Math.min(m.overflow, m.queue.length); i++) {
    const q = m.queue[i];
    add({ d: q.u + q.v + 0.5, kind: 'queue', u: q.u, v: q.v }, () => drawCharacter(c, o, look.chars.get('octopus') ?? OCTOPUS, look.agentColors[i % look.agentColors.length], q.u + 0.5, q.v + 0.5, 'nw', 'stand', 0));
  }
  for (const x of w.actors) {
    if (x.hidden) continue;
    add({ d: x.u + x.v + 0.5, kind: 'actor', u: x.u, v: x.v, key: x.key }, () => drawActor(c, o, x, now, look));

  items.sort((a, b) => a.d - b.d);
  for (const it of items) if (!pick || pick(it)) it.draw();
}

function glowPass(c: Ctx, w: World, sz: SceneSize, look: Look) {
  const m = w.map;
  const o: [number, number] = [sz.ox, sz.oy];
  const [wu0, wu1] = m.wall.window, [su0, su1] = m.wall.screen;
  const flick = flickering(look);
  const glow = (u: number, v: number, h: number, r: number, col: string) => {
    const [x, y] = pt(o[0], o[1], u, v, h);
    const g = c.createRadialGradient(x, y, 0, x, y, r);
    g.addColorStop(0, col);
    g.addColorStop(1, 'rgba(0,0,0,0)');
    c.fillStyle = g;
    c.fillRect(x - r, y - r, r * 2, r * 2);
  };
  for (const s of m.seats) {
    const a = s.key ? w.actors.find((x) => x.key === s.key) : undefined;
    const scr = a?.screen ?? 'off';
    if (scr === 'off') continue;
    glow(s.u + 1, s.v + 0.6, 10, 30, scr === 'game' ? 'rgba(255,110,50,0.42)' : scr === 'bsod' ? 'rgba(60,120,255,0.5)' : 'rgba(60,230,200,0.36)');
  }
  glow(1.5, m.admin.v + 0.5, 30, 44, 'rgba(255,200,120,0.45)'); // the counter's lamp
  glow(0.6, 5, 14, 30, 'rgba(120,220,255,0.45)'); // the fridge
  glow((su0 + su1) / 2, 0, 30, 46, look.mainBusy ? 'rgba(60,220,200,0.30)' : 'rgba(60,140,200,0.18)'); // the big screen
  glow((wu0 + wu1) / 2, 0, 28, 40, 'rgba(90,140,255,0.22)'); // the window
  if (!flick) for (let u = 4; u < m.cols; u += 8) glow(u, 0, 48, 26, 'rgba(255,60,190,0.28)');
  for (let v = 3; v < m.rows; v += 7) glow(0, v, 48, 24, 'rgba(60,220,255,0.24)');
  for (const mc of m.machines) glow(mc.u + 0.5, mc.v + 0.5, 8, 18, 'rgba(80,255,140,0.28)');
  glow(1, m.rows - 8, 8, 14, 'rgba(80,255,140,0.2)'); // the power-bank cabinet
  glow(m.door.u + 0.5, m.door.v + 0.5, 2, 22, 'rgba(80,255,140,0.22)'); // the door mat
}

/** Night: everything drawn so far multiplied dark. */
export function darken(c: Ctx, sz: SceneSize) {
  c.globalCompositeOperation = 'multiply';
  c.fillStyle = 'rgb(150,140,188)';
  c.fillRect(0, 0, sz.w, sz.h);
  c.globalCompositeOperation = 'source-over';
}

/** The light sources, added ('lighter'): over the darkened room, or on a transparent canvas of their own. */
export function drawGlows(c: Ctx, w: World, sz: SceneSize, look: Look) {
  c.globalCompositeOperation = 'lighter';
  glowPass(c, w, sz, look);
  c.globalCompositeOperation = 'source-over';
}

/** The product's lighting: darken, then the light sources. */
export function drawLight(c: Ctx, w: World, sz: SceneSize, look: Look) {
  c.globalCompositeOperation = 'multiply';
  c.fillStyle = 'rgb(150,140,188)';
  c.fillRect(0, 0, sz.w, sz.h);
  c.globalCompositeOperation = 'lighter';
  glowPass(c, w, sz, look);
  c.globalCompositeOperation = 'source-over';
}

export function render(out: Ctx, cw: number, ch: number, w: World, view: View, look: Look) {
  const sz = sceneSize(w.map);
  const c = scene(sz.w, sz.h);
  if (!c) return;
  drawRoom(c, w, sz, look);
  drawItems(c, w, sz, look);
  drawLight(c, w, sz, look);

  // ---- onto the page ----
  out.setTransform(1, 0, 0, 1, 0, 0);
  out.fillStyle = '#08070b';
  out.fillRect(0, 0, cw, ch);
  out.imageSmoothingEnabled = false;
  out.drawImage(sceneCan!, Math.round(view.x), Math.round(view.y), Math.round(sz.w * view.scale), Math.round(sz.h * view.scale));
  labels(out, w, view, sz, look);
}
```

```ts
// The English of the texts the café engine draws (sign, door pill, receipts, the admin's shouts…), for the site's
// shim (src/hero/engine-i18n.ts). The keys are found with the shared scanner in the engine files the site bundles;
// the English comes from the product's catalogs. Never import those catalogs into the browser (420 KB together).
//   node site/scripts/engine-en.ts      (also prebuild / pretest)
import fs from 'node:fs';
import path from 'node:path';
import { pathToFileURL } from 'node:url';
import { keysIn } from '../../scripts/i18n/scan.mjs';
import { readCatalog, root } from '../../scripts/i18n/catalog.mjs';

/** What the site bundles from the engine and calls tr() (validate.ts too, but its texts never show on the site). */
export const ENGINE_FILES = [
  'web/src/features/cafe/map.ts',
  'web/src/features/cafe/sim.ts',
  'web/src/features/cafe/render.ts',
  'web/src/features/cafe/money.ts',
  'server/src/characters/core/builtin.ts',
];
export const OUT = path.join(root, 'site/src/hero/engine-en.generated.ts');

export function engineEnglish(): { entries: Record<string, string>; missing: string[] } {
  const web = readCatalog({ catalog: 'web/src/i18n/en.ts', export: 'EN_WEB' });
  const server = readCatalog({ catalog: 'server/src/i18n/en.ts', export: 'EN_SERVER' });
  const keys = new Set<string>();
  for (const rel of ENGINE_FILES) {
    const file = path.join(root, rel);
    for (const k of keysIn(file, fs.readFileSync(file, 'utf8')).keys) keys.add(k.key);
  }
  const entries: Record<string, string> = {};
  const missing: string[] = [];
  for (const k of [...keys].sort()) {
    const en = web[k] ?? server[k];
    if (en === undefined) missing.push(k); else entries[k] = en;
  }
  return { entries, missing };
}

export function generated(entries: Record<string, string>): string {
  const body = Object.keys(entries).sort().map((k) => `  ${JSON.stringify(k)}: ${JSON.stringify(entries[k])},`).join('\n');
  return `// GENERATED by site/scripts/engine-en.ts from the product's catalogs — do not edit.\nexport const ENGINE_EN: Record<string, string> = {\n${body}\n};\n`;
}

if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) {
  const { entries, missing } = engineEnglish();
  if (missing.length) {
    console.error(`engine-en: no English for ${missing.length} text(s):\n${missing.map((k) => `  ${k}`).join('\n')}`);
    process.exit(1);
  }
  const text = generated(entries);
  if (!fs.existsSync(OUT) || fs.readFileSync(OUT, 'utf8') !== text) fs.writeFileSync(OUT, text);
  console.log(`engine-en: ${Object.keys(entries).length} texts`);
}
```

```js
// The café engine on the site (docs/superpowers/plans/2026-10-22-site-2-hero.md): the same aliases as web/vite.config.ts
// for the files the site bundles, '@/i18n' to the site's shim, and the characters' core's '../../i18n/index.js' (the
// server's i18n, which registers the server's 110 KB English) to the same shim. Shared by astro.config.mjs and vitest.config.ts.
import path from 'node:path';

const slash = (p) => p.replaceAll('\\', '/');

export function engineAlias(site) {
  const repo = path.resolve(site, '..');
  return [
    { find: /^@i18n$/, replacement: slash(path.join(repo, 'server/src/i18n/core.ts')) },
    { find: /^@\/i18n$/, replacement: slash(path.join(site, 'src/hero/engine-i18n.ts')) },
    { find: /^@cafe\//, replacement: `${slash(path.join(repo, 'web/src/features/cafe'))}/` },
    { find: /^@characters$/, replacement: slash(path.join(repo, 'server/src/characters/core/index.ts')) },
    { find: /^@shared$/, replacement: slash(path.join(repo, 'server/src/protocol.ts')) },
  ];
}

export function engineI18n(site) {
  const core = path.normalize(path.join(path.resolve(site, '..'), 'server/src/characters/core'));
  const shim = slash(path.join(site, 'src/hero/engine-i18n.ts'));
  return {
    name: 'site-engine-i18n',
    enforce: 'pre',
    resolveId(source, importer) {
      if (source === '../../i18n/index.js' && importer && path.normalize(importer.split('?')[0]).startsWith(core)) return shim;
      return null;
    },
  };
}
```

```ts
// The site's demo day (spec §4.1): a 60 s loop of the conversation's background, fed to the product's café sim
// exactly as the app feeds it, at a fixed seed — every visitor sees the same show.
//   0 s nobody · 3 s api / tests / docs come in · ~12 s docs (nothing to do) goes for noodles · 18 s api needs you
//   (its beats stop; the site shows a permission card) · 24 s tests done → pays · 30 s lint (another colour) comes
//   in, docs back to work · 40 s all done → they pay and leave · 60 s again.
import { createWorld, step, type BgAgent, type BgSession, type BgTask, type World } from './engine';

export const EPOCH = 1_800_000_000_000;
export const LOOP_MS = 60_000;
export const STEP_MS = 50;
export const POSTER_MS = 20_000;
/** Chosen so docs' first idle pick is the noodles (demo.test.ts "docs goes for noodles"). */
export const DEMO_SEED = 7;

export type DemoPhase = 'idle' | 'arrive' | 'noodles' | 'needsYou' | 'checkout' | 'guest' | 'done';
export const PHASE_START: Record<DemoPhase, number> = { idle: 0, arrive: 3000, noodles: 12_000, needsYou: 18_000, checkout: 24_000, guest: 30_000, done: 40_000 };
const ORDER = Object.entries(PHASE_START).sort((a, b) => a[1] - b[1]) as [DemoPhase, number][];

export function phaseAt(t: number): DemoPhase {
  let p: DemoPhase = 'idle';
  for (const [name, start] of ORDER) if (t >= start) p = name;
  return p;
}

export interface Decision { at: number; allow: boolean }

export const GUESTS = { api: 'api/api', tests: 'tests/tests', docs: 'docs/docs', lint: 'lint/lint' } as const;

const NEEDS_FROM = PHASE_START.needsYou, NEEDS_TO = PHASE_START.checkout;
const STEPS: Record<string, string[]> = {
  api: ['Read src/cart.ts', 'Grep applyCoupon', 'Edit src/cart.ts', 'Bash npm test'],
  tests: ['Read tests/cart.test.ts', 'Edit tests/cart.test.ts', 'Bash npx vitest run'],
  docs: ['Read README.md', 'Edit docs/cart.md'],
  lint: ['Bash npm run lint', 'Edit src/orders.ts'],
};

interface Plan { id: string; color: number; start: number; end: number; beatFrom: number; noStart?: boolean; paused?: (t: number) => boolean }

function plans(decision: Decision | undefined): Plan[] {
  const resumed = decision?.at ?? NEEDS_TO;
  return [
    { id: 'api', color: 1, start: 3000, end: 40_000, beatFrom: 3000, paused: (t) => t >= NEEDS_FROM && t < resumed },
    { id: 'tests', color: 2, start: 3001, end: 24_000, beatFrom: 3001 },
    // no start time and no beats until 30 s: idle the moment it sits down
    { id: 'docs', color: 3, start: 3002, end: 40_000, beatFrom: 30_000, noStart: true },
    { id: 'lint', color: 5, start: 30_000, end: 40_000, beatFrom: 30_000 },
  ];
}

function agentAt(p: Plan, t: number): BgAgent {
  const done = t >= p.end;
  const until = Math.min(t, p.end);
  const beats: number[] = [];
  for (let b = p.beatFrom; b <= until; b += 2000) if (!p.paused?.(b)) beats.push(EPOCH + b);
  const steps = STEPS[p.id];
  return {
    key: p.id, color: p.color, label: p.id, state: done ? 'done' : 'running', model: 'claude-sonnet-4-5',
    ...(p.noStart ? {} : { startedAt: EPOCH + p.start }),
    ...(done ? { endedAt: EPOCH + p.end } : {}),
    tokens: Math.round(((until - p.start) / 1000) * 900),
    toolCalls: beats.length,
    ...(beats.length ? { lastSummary: steps[(beats.length - 1) % steps.length], lastTool: steps[(beats.length - 1) % steps.length].split(' ')[0] } : {}),
    beats: beats.slice(-24),
  };
}

export function snapshotAt(t: number, decision?: Decision): BgSession {
  const tasks: BgTask[] = [];
  for (const p of plans(decision)) {
    if (t < p.start) continue;
    const a = agentAt(p, t);
    tasks.push({
      id: p.id, kind: 'agent', description: p.id, status: a.state === 'done' ? 'completed' : 'running', startedAt: EPOCH + p.start,
      ...(a.state === 'done' ? { endedAt: EPOCH + p.end } : {}), tokens: a.tokens, agents: [a],
    });
  }
  return { sessionId: 'demo', updatedAt: EPOCH + t, tasks, events: [] };
}

export class Demo {
  t = 0;
  world: World;
  decision: Decision | undefined;
  private acc = 0;
  private snap: { key: string; s: BgSession } | undefined;

  constructor(private readonly seed = DEMO_SEED, private readonly rate = 5) {
    this.world = createWorld(seed, EPOCH);
  }

  now(): number { return EPOCH + this.t; }

  /** The snapshot for now; the same object for 250 ms (the sim rebuilds the plan when the snapshot changes). */
  snapshot(): BgSession {
    const key = `${Math.floor(this.t / 250)}|${this.decision ? `${this.decision.at}${this.decision.allow}` : ''}`;
    if (this.snap?.key !== key) this.snap = { key, s: snapshotAt(this.t, this.decision) };
    return this.snap.s;
  }

  /** Move the clock on in fixed 50 ms steps (the remainder waits for the next call); past 60 s it starts again. */
  advance(dtMs: number, reduced = false): void {
    this.acc += Math.max(0, dtMs);
    while (this.acc >= STEP_MS - 1e-6) {
      this.acc -= STEP_MS;
      this.t += STEP_MS;
      // reset() clears the remainder: keep it, the rest of this call plays in the new loop
      if (this.t >= LOOP_MS) { const left = this.acc; this.reset(); this.acc = left; continue; }
      this.world = step(this.world, this.snapshot(), this.now(), { rate: this.rate, mainBusy: true, reduced });
    }
  }

  seek(ms: number): void {
    this.reset();
    this.advance(Math.min(ms, LOOP_MS - STEP_MS));
  }

  jumpTo(p: DemoPhase): void { this.seek(PHASE_START[p]); }

  phase(): DemoPhase { return phaseAt(this.t); }

  needsYou(): boolean { return this.t >= NEEDS_FROM && this.t < NEEDS_TO && !this.decision; }

  decide(allow: boolean): void {
    if (this.needsYou()) this.decision = { at: this.t, allow };
  }

  reset(): void {
    this.t = 0;
    this.acc = 0;
    this.decision = undefined;
    this.snap = undefined;
    this.world = createWorld(this.seed, EPOCH);
  }
}
```

`loops with the same seed`：`advance(61000)` 在 60 000 处 `reset()`，余下的 1000 ms 在新一轮里走完，所以 `t === 1000`。

```ts
// Three tiers of the hero (spec §7): T0 layered canvas + WebGL post, T1 layered canvas only (phones: no parallax,
// ≤ 24 fps, tap to lock), T2 the poster image. Pure: readTierEnv() gathers the facts in the browser.
export type Tier = 'T0' | 'T1' | 'T2';
export interface TierEnv { reducedMotion: boolean; canvas: boolean; crawler: boolean; finePointer: boolean; cores: number; webgl2: boolean; renderer: string }
export interface TierProfile { tier: Tier; live: boolean; post: boolean; parallax: boolean; maxFps: number; tapLock: boolean }

export const CRAWLER = /bot\b|bot\/|crawl|spider|slurp|facebookexternalhit|embedly|whatsapp|telegram|discord|preview/i;

export function tierOf(e: TierEnv): Tier {
  if (e.reducedMotion || !e.canvas || e.crawler) return 'T2';
  if (e.finePointer && e.cores > 4 && e.webgl2 && !/swiftshader/i.test(e.renderer)) return 'T0';
  return 'T1';
}

export function profileOf(tier: Tier, finePointer: boolean): TierProfile {
  if (tier === 'T2') return { tier, live: false, post: false, parallax: false, maxFps: 0, tapLock: false };
  if (tier === 'T0') return { tier, live: true, post: true, parallax: true, maxFps: 60, tapLock: false };
  return finePointer
    ? { tier, live: true, post: false, parallax: true, maxFps: 60, tapLock: false }
    : { tier, live: true, post: false, parallax: false, maxFps: 24, tapLock: true };
}

export function readTierEnv(): TierEnv {
  const mm = (q: string) => !!window.matchMedia?.(q).matches;
  const probe = document.createElement('canvas');
  let webgl2 = false, renderer = '';
  try {
    const gl = probe.getContext('webgl2');
    if (gl) {
      webgl2 = true;
      const info = gl.getExtension('WEBGL_debug_renderer_info');
      renderer = String(info ? gl.getParameter(info.UNMASKED_RENDERER_WEBGL) : gl.getParameter(gl.RENDERER));
      gl.getExtension('WEBGL_lose_context')?.loseContext();
    }
  } catch { /* no WebGL */ }
  let canvas = false;
  try { canvas = !!document.createElement('canvas').getContext('2d'); } catch { /* none */ }
  return {
    reducedMotion: mm('(prefers-reduced-motion: reduce)'),
    canvas,
    crawler: CRAWLER.test(navigator.userAgent),
    finePointer: mm('(pointer: fine)') && mm('(hover: hover)'),
    cores: navigator.hardwareConcurrency || 2,
    webgl2,
    renderer,
  };
```

```ts
// Parallax (spec §4.2): each layer moves factor × 12 native px with the pointer, eased.
export const LAYER_FACTORS = [0.4, 0.7, 1.0, 0.55] as const;
export const MAX_SHIFT = 12;

const clamp1 = (n: number) => Math.max(-1, Math.min(1, n));

export function pointerNorm(clientX: number, clientY: number, rect: { left: number; top: number; width: number; height: number }): { x: number; y: number } {
  return {
    x: clamp1(((clientX - rect.left) / Math.max(1, rect.width)) * 2 - 1),
    y: clamp1(((clientY - rect.top) / Math.max(1, rect.height)) * 2 - 1),
  };
}

export function parallaxOffset(p: { x: number; y: number }, factor: number, max = MAX_SHIFT): { x: number; y: number } {
  const r = (n: number) => Math.round(n * 1000) / 1000;
  return { x: r(clamp1(p.x) * factor * max), y: r(clamp1(p.y) * factor * max) };
}

/** Exponential smoothing: the same feel at any frame rate, never past the target. */
export function approach(cur: number, target: number, dtMs: number, tauMs = 140): number {
  if (cur === target) return cur;
  return cur + (target - cur) * (1 - Math.exp(-Math.max(0, dtMs) / tauMs));
}
```

```ts
// The layered picture of the café (spec §4.2): four canvases at the room's native size — L0 the room, L1 what stands
// behind, L2 the front (counter, admin, door side, glass), L3 the light alone — composited onto the page canvas with
// per-layer parallax and nearest-neighbour upscaling; the labels go on a canvas of their own at the page's resolution.
import { darken, drawGlows, drawItems, drawRoom, labels, sceneSize, type Look, type SceneSize, type View, type World } from './engine';
import { isFront } from './layers';
import { approach, LAYER_FACTORS, parallaxOffset } from './motion';

export interface FrameInput { world: World; view: View; pointer: { x: number; y: number } | null; look: Look; dtMs: number; cw: number; ch: number }

/** The seam for another renderer (a real 3D one later, spec §7): tier.ts picks, main.ts drives. */
export interface SceneRenderer {
  mount(el: HTMLElement): void;
  frame(f: FrameInput): void;
  unmount(): void;
}

function canvas(cls?: string): HTMLCanvasElement {
  const c = document.createElement('canvas');
  if (cls) { c.className = cls; c.setAttribute('aria-hidden', 'true'); }
  return c;
}
const ctx2d = (c: HTMLCanvasElement) => c.getContext('2d')!;

export class LayeredCanvas implements SceneRenderer {
  readonly paint = canvas('scene-paint');
  readonly ui = canvas('scene-ui');
  readonly layers = [canvas(), canvas(), canvas(), canvas()];
  readonly offsets = LAYER_FACTORS.map(() => ({ x: 0, y: 0 }));
  glowRect = { x: 0, y: 0, w: 1, h: 1 };
  private readonly pre = canvas();

  constructor(private readonly opts: { parallax: boolean }) {}

  mount(el: HTMLElement) { el.append(this.paint, this.ui); }
  unmount() { this.paint.remove(); this.ui.remove(); }

  /** The page canvases follow the element's size (device pixels, at most 2× CSS). */
  size(el: HTMLElement): { w: number; h: number; dpr: number } {
    const r = el.getBoundingClientRect();
    const dpr = Math.min(2, window.devicePixelRatio || 1);
    const w = Math.max(1, Math.round(r.width * dpr)), h = Math.max(1, Math.round(r.height * dpr));
    for (const c of [this.paint, this.ui]) if (c.width !== w || c.height !== h) { c.width = w; c.height = h; }
    return { w, h, dpr };
  }

  private fit(sz: SceneSize) {
    for (const c of [...this.layers, this.pre]) if (c.width !== sz.w || c.height !== sz.h) { c.width = sz.w; c.height = sz.h; }
  }

  /** Darken a layer of standing things: multiply would paint its transparent area, so its alpha comes back from a copy. */
  private shade(c: CanvasRenderingContext2D, sz: SceneSize) {
    const p = ctx2d(this.pre);
    p.clearRect(0, 0, sz.w, sz.h);
    p.drawImage(c.canvas, 0, 0);
    darken(c, sz);
    c.globalCompositeOperation = 'destination-in';
    c.drawImage(this.pre, 0, 0);
    c.globalCompositeOperation = 'source-over';
  }

  frame(f: FrameInput) {
    const { world: w, view, look } = f;
    const sz = sceneSize(w.map);
    this.fit(sz);
    const [l0, l1, l2, l3] = this.layers.map(ctx2d);
    l0.clearRect(0, 0, sz.w, sz.h);
    drawRoom(l0, w, sz, look);
    darken(l0, sz);
    for (const [c, front] of [[l1, false], [l2, true]] as const) {
      c.clearRect(0, 0, sz.w, sz.h);
      drawItems(c, w, sz, look, (t) => isFront(t, w.map) === front);
      this.shade(c, sz);
    }
    l3.clearRect(0, 0, sz.w, sz.h);
    drawGlows(l3, w, sz, look);

    LAYER_FACTORS.forEach((k, i) => {
      const target = this.opts.parallax && f.pointer ? parallaxOffset(f.pointer, k) : { x: 0, y: 0 };
      const o = this.offsets[i];
      o.x = approach(o.x, target.x, f.dtMs);
      o.y = approach(o.y, target.y, f.dtMs);
    });

    const out = ctx2d(this.paint);
    out.setTransform(1, 0, 0, 1, 0, 0);
    out.globalCompositeOperation = 'source-over';
    out.globalAlpha = 1;
    out.fillStyle = '#08070b';
    out.fillRect(0, 0, f.cw, f.ch);
    out.imageSmoothingEnabled = false;
    const W = Math.round(sz.w * view.scale), H = Math.round(sz.h * view.scale);
    const at = (i: number) => ({ x: Math.round(view.x + this.offsets[i].x * view.scale), y: Math.round(view.y + this.offsets[i].y * view.scale) });
    for (let i = 0; i < 3; i++) { const p = at(i); out.drawImage(this.layers[i], p.x, p.y, W, H); }
    // the light breathes a little with the pointer's distance from the centre
    const breath = f.pointer ? Math.min(1, Math.hypot(f.pointer.x, f.pointer.y) / Math.SQRT2) : 0;
    const g = at(3);
    out.globalCompositeOperation = 'lighter';
    out.globalAlpha = 0.9 + 0.1 * breath;
    out.drawImage(this.layers[3], g.x, g.y, W, H);
    out.globalAlpha = 1;
    out.globalCompositeOperation = 'source-over';
    this.glowRect = { x: g.x, y: g.y, w: W, h: H };

    const ui = ctx2d(this.ui);
    ui.setTransform(1, 0, 0, 1, 0, 0);
    ui.clearRect(0, 0, f.cw, f.ch);
    labels(ui, w, view, sz, look);
  }
}
```

```ts
// The hero's live scene (lazily imported by entry.ts): the demo day stepped every frame, drawn by the layered renderer,
// the camera eased to whatever the chapters ask. Later parts plug in through hero.tweaks / hero.onFrame.
import { BUILTIN, resolveCharacter, sceneSize, type Look, type View, type World } from './engine';
import { Demo, POSTER_MS } from './demo';
import { AGENT_NIGHT } from './palette';
import { LayeredCanvas } from './Scene';
import { anchorFor, cameraView, CAMERA_MS, easeView, HERO_LOOK, type ChapterLook } from './chapters';
import { pointerNorm } from './motion';
import type { TierProfile } from './tier';

export interface HeroOptions { profile: TierProfile; poster: boolean }
export interface Hero {
  root: HTMLElement;
  demo: Demo;
  renderer: LayeredCanvas;
  profile: TierProfile;
  poster: boolean;
  /** Device pixels per CSS pixel of the canvases. */
  dpr: number;
  /** The camera of the last frame (device px). */
  view: View;
  /** The pointer over the stage, -1…1 (null: elsewhere, or no mouse). */
  pointer: { x: number; y: number } | null;
  /** The same in client (CSS) px. */
  client: { x: number; y: number } | null;
  /** The actor key under the pointer (its seat tag lights up). */
  hover: string | undefined;
  /** Demo speed (the debug panel). */
  speed: number;
  still: boolean;
  tweaks: ((w: World, now: number) => World)[];
  onFrame: ((dtMs: number) => void)[];
  lookAt(look: ChapterLook): void;
  look(): Look;
  start(): void;
  stop(): void;
}

const chars = new Map(BUILTIN.map((c) => [c.id, c]));
const BOOT_STEP_MS = 120;

/** Monitors switch on one by one when the scene takes over from the poster. */
function booting(w: World, elapsed: number): World {
  return { ...w, actors: w.actors.map((a) => (a.seat && elapsed < a.seat * BOOT_STEP_MS ? { ...a, screen: 'off' as const } : a)) };
}

export function startHero(root: HTMLElement, opts: HeroOptions): Hero {
  const demo = new Demo();
  demo.seek(POSTER_MS);
  const renderer = new LayeredCanvas({ parallax: opts.profile.parallax });
  renderer.mount(root);
  let camFrom: View | null = null, camTo: ChapterLook = HERO_LOOK, camAt = 0;
  let raf = 0, last = 0, lastDraw = 0, bootAt = 0, running = false, onScreen = true;

  const hero: Hero = {
    root, demo, renderer, profile: opts.profile, poster: opts.poster, dpr: 1, view: { scale: 1, x: 0, y: 0 },
    pointer: null, client: null, hover: undefined, speed: 1, still: opts.poster, tweaks: [], onFrame: [],
    lookAt(look) {
      if (look === camTo) return;
      camFrom = { ...hero.view };
      camTo = look;
      camAt = performance.now();
    },
    look: () => ({
      now: hero.demo.now(), agentColors: AGENT_NIGHT, chars, rate: 5, session: hero.demo.snapshot(), hover: hero.hover, still: hero.still, mainBusy: true, title: '',
      who: (x) => resolveCharacter(undefined, x.key === 'admin' ? { admin: true } : { type: x.type, name: x.name }, (id) => chars.has(id)),
    }),
    start() { if (running || hero.still) return; running = true; last = 0; raf = requestAnimationFrame(tick); },
    stop() { running = false; cancelAnimationFrame(raf); },
  };

  function draw(t: number) {
    const dt = last ? Math.min(250, t - last) : 16;
    last = t;
    if (!hero.still) hero.demo.advance(dt * hero.speed, false);
    const { w: cw, h: ch, dpr } = renderer.size(root);
    hero.dpr = dpr;
    const sz = sceneSize(hero.demo.world.map);
    const target = cameraView(camTo, sz, cw, ch, anchorFor(cw / dpr));
    hero.view = camFrom ? easeView(camFrom, target, (t - camAt) / CAMERA_MS) : target;
    if (camFrom && t - camAt >= CAMERA_MS) camFrom = null;
    let w = hero.demo.world;
    if (!bootAt) bootAt = t;
    if (!hero.still) w = booting(w, t - bootAt);
    for (const f of hero.tweaks) w = f(w, hero.demo.now());
    renderer.frame({ world: w, view: hero.view, pointer: hero.pointer, look: hero.look(), dtMs: dt, cw, ch });
    for (const f of hero.onFrame) f(dt);
    root.dataset.live = '1';
  }

  function tick(t: number) {
    raf = requestAnimationFrame(tick);
    if (t - lastDraw < 1000 / opts.profile.maxFps - 1) return;
    lastDraw = t;
    draw(t);
  }

  addEventListener('pointermove', (e) => {
    if (e.pointerType !== 'mouse') return;
    const r = root.getBoundingClientRect();
    const inside = e.clientX >= r.left && e.clientX <= r.right && e.clientY >= r.top && e.clientY <= r.bottom;
    hero.pointer = inside ? pointerNorm(e.clientX, e.clientY, r) : null;
    hero.client = inside ? { x: e.clientX, y: e.clientY } : null;
  }, { passive: true });
  document.documentElement.addEventListener('pointerleave', () => { hero.pointer = null; hero.client = null; });

  // no frames while the tab is hidden or the stage is scrolled away
  const sync = () => (onScreen && !document.hidden ? hero.start() : hero.stop());
  document.addEventListener('visibilitychange', sync);
  new IntersectionObserver(([e]) => { onScreen = e.isIntersecting; sync(); }).observe(document.getElementById('stage') ?? root);

  if (hero.still) {
    draw(performance.now());
    document.fonts.ready.then(() => {
      draw(performance.now());
      document.documentElement.dataset.posterReady = '1';
    });
  } else sync();
  return hero;
}
```

```js
// A static server for site/dist (the poster and smoke scripts): a folder serves its index.html.
const fs = require('node:fs');
const http = require('node:http');
const path = require('node:path');

const TYPES = { '.html': 'text/html; charset=utf-8', '.js': 'text/javascript', '.css': 'text/css', '.svg': 'image/svg+xml', '.png': 'image/png', '.webp': 'image/webp', '.gif': 'image/gif', '.woff2': 'font/woff2', '.json': 'application/json', '.txt': 'text/plain; charset=utf-8', '.xml': 'application/xml' };

function serve(dir) {
  return new Promise((resolve) => {
    const srv = http.createServer((req, res) => {
      let p = decodeURIComponent(new URL(req.url, 'http://x').pathname);
      let f = path.join(dir, p);
      if (!f.startsWith(dir)) { res.writeHead(403).end(); return; }
      if (fs.existsSync(f) && fs.statSync(f).isDirectory()) f = path.join(f, 'index.html');
      if (!fs.existsSync(f)) { res.writeHead(404).end('not found'); return; }
      res.writeHead(200, { 'content-type': TYPES[path.extname(f)] ?? 'application/octet-stream' });
      fs.createReadStream(f).pipe(res);
    });
    srv.listen(0, '127.0.0.1', () => resolve({ url: `http://127.0.0.1:${srv.address().port}`, close: () => srv.close() }));
  });
}

module.exports = { serve };
```

- [ ] **Step 8: 章节控制 `site/src/hero/overlays.ts`**

```ts
// The chapters drive the scene (spec §4.3): the one crossing the middle of the viewport sets the camera, the demo phase
// it needs, the scene's aria-label, and which card hangs over the scene; the cards are real buttons.
import { onPage, sceneSize } from './engine';
import { CHAPTERS, chapterById, HERO_LOOK, type ChapterSpec } from './chapters';
import { GUESTS } from './demo';
import type { Hero } from './main';

const $ = <T extends Element>(root: ParentNode, sel: string) => root.querySelector<T>(sel);
const RESULT_MS = 2500;

export function installChapters(hero: Hero): { active(): string | null } {
  const root = hero.root;
  const label = $<HTMLElement>(root, '[data-scene-label-el]');
  const heroAlt = label?.getAttribute('aria-label') ?? '';
  const cards = new Map([...root.querySelectorAll<HTMLElement>('[data-overlay]')].map((el) => [el.dataset.overlay!, el]));
  let active: ChapterSpec | null = null;
  let resultUntil = 0;

  function show(spec: ChapterSpec | null, section: HTMLElement | null) {
    active = spec;
    hero.lookAt(spec?.look ?? HERO_LOOK);
    if (spec) root.dataset.chapter = spec.id; else delete root.dataset.chapter;
    label?.setAttribute('aria-label', section?.dataset.sceneLabel ?? heroAlt);
    if (spec?.jump && (!spec.ok.includes(hero.demo.phase()) || (spec.id === 'permission' && !hero.demo.needsYou()))) hero.demo.jumpTo(spec.jump);
    for (const [id, el] of cards) el.hidden = id !== spec?.id;
  }

  // the section crossing the middle line of the viewport is the active one
  const io = new IntersectionObserver((entries) => {
    for (const e of entries) {
      if (!e.isIntersecting) continue;
      const el = e.target as HTMLElement;
      show(el.dataset.chapter ? chapterById(el.dataset.chapter) ?? null : null, el.dataset.chapter ? el : null);
    }
  }, { rootMargin: '-50% 0px -50% 0px' });
  const hs = document.querySelector('[data-hero]');
  if (hs) io.observe(hs);
  for (const s of document.querySelectorAll('section.chapter[data-chapter]')) io.observe(s);

  // hang the active card over its guest (or over the camera's point)
  hero.onFrame.push(() => {
    if (!active) return;
    const el = cards.get(active.id);
    if (!el) return;
    if (active.id === 'permission') el.hidden = !hero.demo.needsYou() && performance.now() > resultUntil;
    if (el.hidden) return;
    const w = hero.demo.world;
    const sz = sceneSize(w.map);
    const who = active.focus ? w.actors.find((a) => a.key === GUESTS[active!.focus!]) : undefined;
    const p = who ? onPage(hero.view, sz, who.u + 0.5, who.v + 0.5, 34) : onPage(hero.view, sz, active.look.u, active.look.v, (active.look.h ?? 0) + 20);
    const x = p.x / hero.dpr, y = p.y / hero.dpr;
    const r = root.getBoundingClientRect();
    const cx = Math.max(8, Math.min(r.width - el.offsetWidth - 8, x - el.offsetWidth / 2));
    const cy = Math.max(64, Math.min(r.height - el.offsetHeight - 8, y - el.offsetHeight - 12));
    el.style.transform = `translate(${Math.round(cx)}px, ${Math.round(cy)}px)`;
  });

  // the cards' buttons
  const toggle = (btn: HTMLElement | null, panel: HTMLElement | null) => btn?.addEventListener('click', () => {
    const open = btn.getAttribute('aria-expanded') !== 'true';
    btn.setAttribute('aria-expanded', String(open));
    if (panel) panel.hidden = !open;
  });
  toggle($(root, '[data-turn]'), $(root, '[data-timeline]'));
  toggle($(root, '[data-file]'), $(root, '[data-diff]'));
  $<HTMLButtonElement>(root, '[data-run]')?.addEventListener('click', () => { const o = $<HTMLElement>(root, '[data-out]'); if (o) o.hidden = false; });
  const result = $<HTMLElement>(root, '[data-result]');
  for (const b of root.querySelectorAll<HTMLButtonElement>('[data-decide]')) {
    b.addEventListener('click', () => {
      const allow = b.dataset.decide === 'allow';
      hero.demo.decide(allow);
      const text = (allow ? result?.dataset.allowed : result?.dataset.denied) ?? '';
      if (result) result.textContent = text;
      resultUntil = performance.now() + RESULT_MS;
      const api = hero.demo.world.actors.find((a) => a.key === GUESTS.api);
      if (api) api.bubble = { text, until: hero.demo.now() + RESULT_MS };
    });
  }
  return { active: () => active?.id ?? null };
}

export { CHAPTERS };
```

```ts
// Guests near the pointer look at it (spec §5): only the drawn facing changes, the sim never sees it.
import type { Facing } from './engine';

/** The same four directions walking uses (sim.ts facingOf): the bigger of du / dv wins. */
export function faceToward(from: { u: number; v: number }, to: { u: number; v: number }): Facing {
  const du = to.u - (from.u + 0.5), dv = to.v - (from.v + 0.5);
  return Math.abs(du) >= Math.abs(dv) ? (du >= 0 ? 'se' : 'nw') : (dv >= 0 ? 'sw' : 'ne');
}

export function nearest<T extends { u: number; v: number }>(list: T[], p: { u: number; v: number }, n: number, maxDist = 8): T[] {
  return list
    .map((x) => ({ x, d: Math.hypot(x.u + 0.5 - p.u, x.v + 0.5 - p.v) }))
    .filter((e) => e.d <= maxDist)
    .sort((a, b) => a.d - b.d)
    .slice(0, n)
    .map((e) => e.x);
}
```

`site/src/hero/sound.ts`：

```ts
// The café's sounds, synthesised (no audio files): the till's "ding" (the same note as the app's Cafe.tsx) and soft
// key ticks, faster the more guests type. Off until the visitor turns it on.
import type { World } from './engine';

export function tickInterval(busy: number): number {
  return busy <= 0 ? Infinity : Math.round(320 / Math.sqrt(busy));
}

export class Sound {
  on = false;
  private ctx: AudioContext | null = null;
  private noise: AudioBuffer | null = null;
  private next = 0;
  private dinged = -1;

  toggle(): boolean {
    this.on = !this.on;
    if (this.on) {
      try { this.ctx ??= new AudioContext(); void this.ctx.resume(); } catch { this.on = false; }
      this.dinged = -1;
    }
    return this.on;
  }

  private ding() {
    const a = this.ctx!;
    const o = a.createOscillator(), g = a.createGain();
    o.frequency.value = 1568;
    g.gain.setValueAtTime(0.08, a.currentTime);
    g.gain.exponentialRampToValueAtTime(0.0001, a.currentTime + 0.35);
    o.connect(g).connect(a.destination);
    o.start();
    o.stop(a.currentTime + 0.36);
  }

  private tick() {
    const a = this.ctx!;
    if (!this.noise) {
      this.noise = a.createBuffer(1, Math.round(a.sampleRate * 0.03), a.sampleRate);
      const d = this.noise.getChannelData(0);
      for (let i = 0; i < d.length; i++) d[i] = (Math.random() * 2 - 1) * (1 - i / d.length);
    }
    const src = a.createBufferSource(), f = a.createBiquadFilter(), g = a.createGain();
    src.buffer = this.noise;
    f.type = 'bandpass';
    f.frequency.value = 2200 + Math.random() * 800;
    g.gain.value = 0.025;
    src.connect(f).connect(g).connect(a.destination);
    src.start();
  }

  frame(w: World, nowMs: number) {
    if (!this.on || !this.ctx) return;
    const last = w.dings.at(-1) ?? 0;
    if (this.dinged < 0) this.dinged = last;
    else if (last > this.dinged) { this.dinged = last; this.ding(); }
    if (nowMs < this.next) return;
    const busy = w.actors.filter((a) => a.screen === 'code').length;
    if (busy) this.tick();
    const gap = tickInterval(busy);
    this.next = nowMs + (gap === Infinity ? 500 : gap * (0.6 + Math.random() * 0.8));
  }
}
```

```ts
// The scene's small interactions (spec §5): guests turn to the pointer; hovering (tapping) a guest shows what it does;
// ← / → go from guest to guest; hovering "Allow" previews (api's dark monitor lights up); a download button prints a
// receipt at the counter; ↑↑↓↓←→←→BA opens a debug panel; S / the button turns the synthesised sound on.
import { hitTest, sceneSize, toFloor, type Actor, type World } from './engine';
import { Demo, GUESTS, POSTER_MS } from './demo';
import { faceToward, nearest } from './gaze';
import { konamiDetector } from './konami';
import { Sound } from './sound';
import type { Hero } from './main';

type Texts = Record<string, string>;

function doingText(x: Actor, t: Texts): string {
  switch (x.doing) {
    case 'work': return t.work;
    case 'game': return t.game;
    case 'activity': case 'toActivity': return t[x.activity ?? 'stand'] ?? t.stand;
    case 'toDesk': case 'checkin': return t.checkin;
    case 'toCheckout': case 'checkout': return t.checkout;
    case 'leave': return t.leave;
    default: return t.other;
  }
}

const editable = (el: EventTarget | null) => el instanceof HTMLElement && (el.isContentEditable || /^(INPUT|TEXTAREA|SELECT)$/.test(el.tagName));

export function installInteract(hero: Hero): void {
  const root = hero.root;
  const tip = root.querySelector<HTMLElement>('.scene-tip');
  const texts: Texts = JSON.parse(tip?.dataset.doing ?? '{}');
  let preview = false;
  let pinned: { key: string; x: number; y: number } | null = null;

  /** Client (CSS) px → the floor under it, through the middle layer's parallax. */
  function floorAt(cx: number, cy: number): { u: number; v: number; px: number; py: number } {
    const r = root.getBoundingClientRect();
    const px = (cx - r.left) * hero.dpr, py = (cy - r.top) * hero.dpr;
    const sz = sceneSize(hero.demo.world.map);
    const off = hero.renderer.offsets[1];
    const x = (px - hero.view.x) / hero.view.scale - off.x - sz.ox;
    const y = (py - hero.view.y) / hero.view.scale - off.y - sz.oy;
    return { ...toFloor(x, y), px, py };
  }
  const midView = () => ({ ...hero.view, x: hero.view.x + hero.renderer.offsets[1].x * hero.view.scale, y: hero.view.y + hero.renderer.offsets[1].y * hero.view.scale });

  // guests look at the pointer; api's monitor stays dark while it waits for you, lit while "Allow" is hovered
  hero.tweaks.push((w: World) => {
    let actors = w.actors;
    if (hero.demo.needsYou()) actors = actors.map((a) => (a.key === GUESTS.api && a.doing === 'work' ? { ...a, screen: preview ? 'code' : 'off' } : a));
    let admin = w.admin;
    if (hero.client && hero.profile.parallax) {
      const f = floorAt(hero.client.x, hero.client.y);
      const standing = [...actors.filter((a) => !a.hidden && (a.pose === 'stand' || a.pose === 'eat')), ...(admin.pose === 'stand' ? [admin] : [])];
      const near = new Set(nearest(standing, f, 3).map((a) => a.key));
      actors = actors.map((a) => (near.has(a.key) ? { ...a, facing: faceToward(a, f) } : a));
      if (near.has('admin')) admin = { ...admin, facing: faceToward(admin, f) };
    }
    return actors === w.actors && admin === w.admin ? w : { ...w, actors, admin };
  });

  function tipFor(key: string): string {
    const x = key === 'admin' ? hero.demo.world.admin : hero.demo.world.actors.find((a) => a.key === key);
    if (!x) return '';
    const a = hero.demo.snapshot().tasks.find((t) => t.id === x.taskId)?.agents[0];
    return [x.name, doingText(x, texts), a?.lastSummary ?? ''].filter(Boolean).join('\n');
  }
  function showTip(key: string | null, x = 0, y = 0) {
    hero.hover = key ?? undefined;
    if (!tip) return;
    const text = key ? tipFor(key) : '';
    tip.hidden = !text;
    if (!text) return;
    tip.textContent = text;
    tip.style.transform = `translate(${Math.round(x + 14)}px, ${Math.round(y + 14)}px)`;
  }

  // hover (mouse) and tap (touch) a guest
  hero.onFrame.push(() => {
    if (pinned) { showTip(pinned.key, pinned.x, pinned.y); return; }
    if (!hero.client) { if (hero.hover) showTip(null); return; }
    const f = floorAt(hero.client.x, hero.client.y);
    const hit = hitTest(hero.demo.world, midView(), f.px, f.py);
    const r = root.getBoundingClientRect();
    showTip(hit && hit.kind !== 'machine' ? hit.key : null, hero.client.x - r.left, hero.client.y - r.top);
  });
  root.addEventListener('click', (e) => {
    if ((e as PointerEvent).pointerType === 'mouse' || (e.target as HTMLElement).closest('button, a, input, .ov')) return;
    const f = floorAt(e.clientX, e.clientY);
    const hit = hitTest(hero.demo.world, midView(), f.px, f.py);
    const r = root.getBoundingClientRect();
    pinned = hit && hit.kind !== 'machine' && pinned?.key !== hit.key ? { key: hit.key, x: e.clientX - r.left, y: e.clientY - r.top } : null;
    if (!pinned) showTip(null);
  });

  // ← / → from guest to guest (the camera follows); Konami
  const konami = konamiDetector();
  let cycle = -1;
  addEventListener('keydown', (e) => {
    if (e.ctrlKey || e.metaKey || e.altKey || editable(e.target)) return;
    if (konami(e.key)) { const d = root.querySelector<HTMLElement>('[data-debug]'); if (d) d.hidden = !d.hidden; return; }
    if (e.key !== 'ArrowLeft' && e.key !== 'ArrowRight') return;
    const r = root.getBoundingClientRect();
    if (r.bottom <= 0 || r.top >= innerHeight) return;
    const guests = hero.demo.world.actors.filter((a) => !a.hidden).sort((a, b) => (a.seat ?? 99) - (b.seat ?? 99));
    if (!guests.length) return;
    cycle = (cycle + (e.key === 'ArrowRight' ? 1 : -1) + guests.length) % guests.length;
    const g = guests[cycle];
    hero.lookAt({ u: g.u + 0.5, v: g.v + 0.5, h: 8, zoom: 2.2 });
    pinned = { key: g.key, x: r.width * 0.64, y: r.height * 0.52 };
  });

  // "Allow" previews
  const allow = root.querySelector<HTMLElement>('[data-decide="allow"]');
  allow?.addEventListener('pointerenter', () => { preview = true; });
  allow?.addEventListener('pointerleave', () => { preview = false; });
  allow?.addEventListener('focus', () => { preview = true; });
  allow?.addEventListener('blur', () => { preview = false; });

  // a download prints a receipt at the counter; the download itself goes on as usual
  for (const a of document.querySelectorAll<HTMLAnchorElement>('[data-key-action="download"]')) {
    a.addEventListener('click', () => {
      const os = document.documentElement.dataset.os === 'mac' ? 'macOS' : 'Windows';
      const w = hero.demo.world, now = hero.demo.now();
      w.receipts = [{ key: `download-${now}`, name: `Claude Web · ${os}`, seat: 0, ms: 0, fee: 0, kind: 'ok', at: now }, ...w.receipts];
      w.dings = [...w.dings, now];
    });
  }

  // the debug panel
  const panel = root.querySelector<HTMLElement>('[data-debug]');
  panel?.querySelector<HTMLInputElement>('[data-speed]')?.addEventListener('input', (e) => { hero.speed = Number((e.target as HTMLInputElement).value) || 1; });
  panel?.querySelector<HTMLButtonElement>('[data-reseed]')?.addEventListener('click', () => {
    const seed = Number(panel.querySelector<HTMLInputElement>('[data-seed]')?.value) || 7;
    hero.demo = new Demo(seed);
    hero.demo.seek(POSTER_MS);
  });
  const fps = panel?.querySelector<HTMLOutputElement>('[data-fps]');
  let frames = 0, since = performance.now();
  hero.onFrame.push(() => {
    frames++;
    const now = performance.now();
    if (now - since >= 1000) { if (fps && !panel!.hidden) fps.value = `${frames} fps`; frames = 0; since = now; }
  });

  // sound
  const sound = new Sound();
  const btn = root.querySelector<HTMLButtonElement>('.scene-sound');
  btn?.addEventListener('click', () => {
    const on = sound.toggle();
    btn.setAttribute('aria-pressed', String(on));
    const label = btn.querySelector('[data-sound-label]');
    if (label) label.textContent = (on ? btn.dataset.on : btn.dataset.off) ?? '';
  });
  hero.onFrame.push(() => sound.frame(hero.demo.world, performance.now()));
}
```

```ts
// Scroll reveals for browsers without animation-timeline (neon.css): mark the page, then show each box once it is in view.
export function installReveal(): void {
  if (typeof CSS !== 'undefined' && CSS.supports('animation-timeline: view()')) return;
  if (!('IntersectionObserver' in window)) return;
  document.documentElement.classList.add('js-reveal');
  const io = new IntersectionObserver((entries) => {
    for (const e of entries) if (e.isIntersecting) { e.target.classList.add('in'); io.unobserve(e.target); }
  }, { rootMargin: '0px 0px -10% 0px' });
  for (const el of document.querySelectorAll('.chapter-card, .stats > div, .install > *')) io.observe(el);
}
```

```ts
// T0's post pass (spec §7): one fullscreen fragment shader over the composited scene — a 4×4 Bayer dither, a cheap
// bloom of the light layer (L3) and a light vignette. No library; if anything fails the plain canvas stays.
import type { Hero } from './main';

export const BAYER4 = [0, 8, 2, 10, 12, 4, 14, 6, 3, 11, 1, 9, 15, 7, 13, 5];

const VERTEX = `#version 300 es
in vec2 aPos;
out vec2 vUv;
void main() { vUv = aPos * 0.5 + 0.5; gl_Position = vec4(aPos, 0.0, 1.0); }`;

export const FRAGMENT = `#version 300 es
precision mediump float;
uniform sampler2D uScene;
uniform sampler2D uGlow;
uniform vec2 uSize;
uniform vec4 uGlowRect;
in vec2 vUv;
out vec4 outColor;
const float B[16] = float[16](${BAYER4.map((n) => `${n}.0`).join(',')});
float bayer(vec2 p) { ivec2 i = ivec2(mod(p, 4.0)); return B[i.y * 4 + i.x] / 16.0 - 0.5; }
void main() {
  vec3 c = texture(uScene, vUv).rgb;
  vec2 px = vec2(vUv.x, 1.0 - vUv.y) * uSize;
  vec2 g = (px - uGlowRect.xy) / uGlowRect.zw;
  vec3 bloom = vec3(0.0);
  vec2 step = 3.0 / vec2(textureSize(uGlow, 0));
  for (int y = -2; y <= 2; y++) for (int x = -2; x <= 2; x++) {
    float w = exp(-float(x * x + y * y) / 4.0);
    bloom += texture(uGlow, vec2(g.x, 1.0 - g.y) + vec2(x, y) * step).rgb * w;
  }
  c += bloom / 10.85 * 0.55;
  c += bayer(gl_FragCoord.xy) / 48.0;
  vec2 d = vUv - 0.5;
  float vignette = 1.0 - dot(d, d) * 0.55;
  outColor = vec4(c * vignette, 1.0);
}`;

function shader(gl: WebGL2RenderingContext, type: number, src: string): WebGLShader | null {
  const s = gl.createShader(type)!;
  gl.shaderSource(s, src);
  gl.compileShader(s);
  return gl.getShaderParameter(s, gl.COMPILE_STATUS) ? s : null;
}

function texture(gl: WebGL2RenderingContext, filter: number): WebGLTexture {
  const t = gl.createTexture()!;
  gl.bindTexture(gl.TEXTURE_2D, t);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, filter);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, filter);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_S, gl.CLAMP_TO_EDGE);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_T, gl.CLAMP_TO_EDGE);
  return t;
}

export function installPost(hero: Hero): boolean {
  const paint = hero.renderer.paint;
  const glow = hero.renderer.layers[3];
  const out = document.createElement('canvas');
  out.className = 'scene-post';
  out.setAttribute('aria-hidden', 'true');
  const gl = out.getContext('webgl2', { antialias: false, premultipliedAlpha: false });
  if (!gl) return false;
  const vs = shader(gl, gl.VERTEX_SHADER, VERTEX), fs = shader(gl, gl.FRAGMENT_SHADER, FRAGMENT);
  if (!vs || !fs) return false;
  const prog = gl.createProgram()!;
  gl.attachShader(prog, vs);
  gl.attachShader(prog, fs);
  gl.linkProgram(prog);
  if (!gl.getProgramParameter(prog, gl.LINK_STATUS)) return false;
  gl.useProgram(prog);
  const buf = gl.createBuffer();
  gl.bindBuffer(gl.ARRAY_BUFFER, buf);
  gl.bufferData(gl.ARRAY_BUFFER, new Float32Array([-1, -1, 1, -1, -1, 1, 1, 1]), gl.STATIC_DRAW);
  const aPos = gl.getAttribLocation(prog, 'aPos');
  gl.enableVertexAttribArray(aPos);
  gl.vertexAttribPointer(aPos, 2, gl.FLOAT, false, 0, 0);
  const uSize = gl.getUniformLocation(prog, 'uSize'), uRect = gl.getUniformLocation(prog, 'uGlowRect');
  gl.uniform1i(gl.getUniformLocation(prog, 'uScene'), 0);
  gl.uniform1i(gl.getUniformLocation(prog, 'uGlow'), 1);
  const tScene = texture(gl, gl.NEAREST), tGlow = texture(gl, gl.LINEAR);
  gl.pixelStorei(gl.UNPACK_FLIP_Y_WEBGL, true);

  let alive = true;
  out.addEventListener('webglcontextlost', (e) => { e.preventDefault(); alive = false; out.remove(); paint.style.visibility = ''; });
  paint.after(out);
  paint.style.visibility = 'hidden';

  hero.onFrame.push(() => {
    if (!alive) return;
    if (out.width !== paint.width || out.height !== paint.height) { out.width = paint.width; out.height = paint.height; }
    gl.viewport(0, 0, out.width, out.height);
    gl.activeTexture(gl.TEXTURE0);
    gl.bindTexture(gl.TEXTURE_2D, tScene);
    gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, gl.RGBA, gl.UNSIGNED_BYTE, paint);
    gl.activeTexture(gl.TEXTURE1);
    gl.bindTexture(gl.TEXTURE_2D, tGlow);
    gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, gl.RGBA, gl.UNSIGNED_BYTE, glow);
    const r = hero.renderer.glowRect;
    gl.uniform2f(uSize, out.width, out.height);
    gl.uniform4f(uRect, r.x, r.y, r.w, r.h);
    gl.drawArrays(gl.TRIANGLE_STRIP, 0, 4);
  });
  return true;
}
```

```ts
/** Local files a stylesheet url()s (fonts, images); not data: URIs or other sites. */
export function cssUrls(css: string, base: string): string[] {
  const out = new Set<string>();
  for (const m of css.matchAll(/url\(\s*(['"]?)([^'")]+)\1\s*\)/g)) {
    const ref = m[2].split(/[?#]/)[0];
    if (ref.startsWith('data:') || ref.startsWith('//') || /^[a-z]+:/i.test(ref)) continue;
    if (ref.startsWith(base)) out.add(ref.slice(base.length));
  }
  return [...out];
}

/** The modules a script imports statically, relative (./x.js) or absolute (/_astro/x.js); import()s are not first load. */
export function staticImports(js: string): string[] {
  return [...js.matchAll(/\bimport\s*(?:[\w$*{}\s,]+?\s*from\s*)?["']((?:\.{1,2})?\/[^"']+)["']/g)].map((m) => m[1]);
}

export function firstLoadFiles(dist: string, html: string, base: string): string[] {
  const seen = new Set<string>();
  const queue = firstLoadRefs(html, base);
  // an inline module script (Astro inlines small ones) imports by absolute path
  for (const m of html.matchAll(/<script[^>]*>([\s\S]*?)<\/script>/gi)) for (const i of staticImports(m[1])) if (i.startsWith(base)) queue.push(i.slice(base.length));
  while (queue.length) {
    const rel = queue.shift()!;
    if (seen.has(rel)) continue;
    const f = path.join(dist, rel);
    if (!fs.existsSync(f)) continue;
    seen.add(rel);
    if (rel.endsWith('.css')) queue.push(...cssUrls(fs.readFileSync(f, 'utf8'), base));
    if (rel.endsWith('.js')) for (const i of staticImports(fs.readFileSync(f, 'utf8'))) queue.push(i.startsWith('/') ? i.slice(base.length) : path.posix.join(path.posix.dirname(rel), i));
  }
  return [...seen];
}

export function firstLoadBytes(dist: string, html: string, base: string): number {
  return firstLoadFiles(dist, html, base).reduce((n, rel) => n + fs.statSync(path.join(dist, rel)).size, Buffer.byteLength(html));
}

/** Scripts in _astro/ that no home page loads up front: what entry.ts import()s (the café scene). */
export function lazyScripts(dist: string, firstLoad: Set<string>): string[] {
  const dir = path.join(dist, '_astro');
  if (!fs.existsSync(dir)) return [];
  return fs.readdirSync(dir).filter((f) => f.endsWith('.js')).map((f) => `_astro/${f}`).filter((rel) => !firstLoad.has(rel)).sort();
}

export function gzipBytes(dist: string, files: string[]): number {
  return files.reduce((n, rel) => n + zlib.gzipSync(fs.readFileSync(path.join(dist, rel)), { level: 9 }).length, 0);
}

if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) {
```

```markdown
  另有一个小插件把 `server/src/characters/core` 里的 `../../i18n/index.js` 改指到同一个垫片（不然服务端 110 KB 英文表会进包）。
  官网只经 `site/src/hero/engine.ts` 拿引擎；不引 `Cafe.tsx` / `state.ts`（zustand、WS），`AGENT_NIGHT` 抄在 `hero/palette.ts`。
- 产品的 `render()` 拆成了 `drawRoom / drawItems(pick) / darken / drawGlows / drawLight / labels`，`render()` 还是同一串调用；
  `web/src/features/cafe/render.test.ts` 用记录调用的假 Canvas 算哈希快照，画面一变就红。改产品网吧的画法时要有意识地 `-u` 更新快照。
- 引擎画的字（招牌、门口牌、小票、网管喊话）按页面 `<html lang>` 出中英；英文是 `site/scripts/engine-en.ts` 从产品两份英文表抽出来的
  `hero/engine-en.generated.ts`（`prebuild` / `pretest` 自动重生成，测试查是否最新、是否缺英文）。产品新加了引擎里的字，官网构建会因缺英文失败——先给产品补英文。
- 分层：L0 房间、L1 后面的东西、L2 前台一带（`hero/layers.ts` 的 `isFront`）、L3 只有光；L1/L2 用 multiply 压暗后要用 `destination-in` 把透明区还原。
  视差系数 0.4 / 0.7 / 1.0 / 0.55，最多 12 个原生像素；触屏关。
- 演示日 `hero/demo.ts`：60 s 循环、固定种子、按 50 ms 定步走（帧长不影响结果），`jumpTo(phase)` 给章节用。引擎没有「举手」状态，「需要你」是 DOM 权限卡；
  docs 去吃泡面靠种子（`DEMO_SEED`），改了 sim 的随机顺序要重找种子（`demo.test.ts` 会红）。
- 三档（`hero/tier.ts`）：T0 桌面鼠标 + 多于 4 核 + 真 WebGL2 → 加后处理（`hero/post.ts`）；T1 其它和手机；T2（减少动画、无 Canvas、爬虫）只有海报。
  标签页隐藏或舞台滚出视口时 rAF 停。
- 首屏海报：`npm run build --prefix site && npm run poster --prefix site`（Electron 打开 `?poster=1`，场景停在第 20 s），同时重做分享图。场景接管时显示器一台台亮，不淡入。
  界面、招牌或演示日改了就重拍。要先跑过一次 `npm run fonts --prefix site`（分享图的字用它的缓存）。
- 像素标题字：Fusion Pixel Font 12px（OFL，许可在 `site/public/fonts/OFL.txt`），按标题用到的字子集化；改了大标题 / 章节标题 / 安装标题要 `npm run fonts --prefix site`（`fonts.test.ts` 会拦）。
  只在 12 的倍数字号下清楚。
- 预算（`site/scripts/budget.ts`）：首页首屏 ≤ 1.5 MB，算 HTML 引用的、CSS `url()` 的字体、首屏脚本静态 import 的；场景（`import()` 进来的）另算，gzip 后 ≤ 400 KB。
- 冒烟：`npm run build --prefix site && env -u ELECTRON_RUN_AS_NODE node site/scripts/smoke.cjs`，逐章滚动、控制台有 error 就失败，截图在临时目录。
- 彩蛋：↑↑↓↓←→←→BA 打开调试面板（速度、种子、fps）；S 开关声音（WebAudio 合成，没有音频文件）。
```
