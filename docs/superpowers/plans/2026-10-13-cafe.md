# 网吧 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把「后台」的 SVG 办公室换成会动的等距像素网吧（子代理是客人：上机、空闲时吃喝玩、结账），加角色库和让模型从照片 / 描述捏角色的 `cafe-character` skill。

**Architecture:** 角色格式和动作变换是一份纯 TS（`server/src/characters/core/`，web 经 `@characters` 别名共用，服务端用它出预览 PNG）。网吧是 `web/src/features/cafe/` 的 Canvas 2D 小引擎：快照 → 地图（纯）→ 模拟（纯、带种子）→ 渲染。角色存 `<dataDir>/characters/`，经 `characters.*` 请求管理；给模型的工具挂在现有的 `web` MCP 服务器上（`mcp__web__character_*`），skill 经 SDK 本地插件带进 Claude 对话。

**Tech Stack:** React 18、Canvas 2D、zustand、Node（`node:zlib` 出 PNG）、vitest、Electron（ui-smoke）。

```ts
export const GRID = 24;
export interface Rig { legs: number; eyes: [number, number][]; hands: [number, number][] }
export interface CharacterDef { v: 1; id: string; name: string; palette: Record<string, string>; front: string[]; back: string[]; rig: Rig; draft?: boolean; builtin?: boolean }
export type Facing = 'se' | 'sw' | 'ne' | 'nw';         // se/sw 用 front（sw 镜像），ne/nw 用 back（nw 镜像）
export type Pose = 'stand' | 'walk' | 'sit' | 'type' | 'game' | 'eat' | 'blink';
export interface Frame { w: number; h: number; px: (string | null)[] }   // 行优先，颜色 '#rrggbb' 或 null
export function validateCharacter(x: unknown): { ok: true; def: CharacterDef } | { ok: false; errors: string[] };
export function poseFrame(def: CharacterDef, facing: Facing, pose: Pose, tick: number): Frame;
export const OCTOPUS: CharacterDef; export const ADMIN: CharacterDef; export const BUILTIN: CharacterDef[];
export interface CafeAssign { admin?: string; default?: string; byType?: Record<string, string>; byName?: Record<string, string> }
export function resolveCharacter(a: CafeAssign | undefined, who: { admin?: boolean; type?: string; name?: string }, exists: (id: string) => boolean): string;
```

规则：`validateCharacter` 的错误是给模型看的中文短句，每条指到位置（「front 第 3 行有 23 个字符，要 24 个」「颜色 #12345 不是 #rrggbb」「front 用了调色板里没有的字母 q（第 5 行第 2 个）」「rig.legs 要在 12–23」「眼睛 (8,9) 在 front 上是透明的」）。`id` `^[a-z0-9-]{1,40}$`、`name` 1–16 字、调色板 1–16 个单字符键（不能是 `.`）。
`poseFrame`：
- 输出 26 宽 × 26 高（四周留 1 格给抖动），先拷 front/back（nw / sw 镜像左右）。
- `walk`：`tick % 4` → 第 1、3 帧 `legs` 以下左半边上移 1 格、右半边不动（3 帧反过来），第 1、3 帧全身上移 1 格。
- `sit`：`legs` 以下的行清空。
- `type` / `game`：sit + 每个 `hands` 坐标画 2×2 手（调色板里最暗的颜色），`tick % 2` 时手下移 1 格（game 用 `tick` 本身，type 用 `tick>>1`）。
- `eat`：sit + 第一只手的位置画碗（3×2 白 `#f2efe6`、上沿红 `#e94e3c`），`tick % 2` 时整体下移 1 格（点头）。
- `blink`：stand + 眼睛那格换成「这个角色调色板里和眼睛颜色以外、出现次数最多的颜色」。
- `resolveCharacter`：admin → `a.admin`；否则 `byName[name]` > `byType[type]` > `default`；不存在的 id 跳过；都没有：admin → `'admin'`，其它 → `'octopus'`。

```ts
import { describe, expect, it } from 'vitest';
import { poseFrame, OCTOPUS } from './index';
const at = (f: any, x: number, y: number) => f.px[y * f.w + x];
describe('poseFrame', () => {
  it('is 26 × 26 and the stand frame is the front image offset by one', () => {
    const f = poseFrame(OCTOPUS, 'se', 'stand', 0);
    expect([f.w, f.h]).toEqual([26, 26]);
    const ch = OCTOPUS.front[10][12];
    expect(at(f, 13, 11)).toBe(ch === '.' ? null : OCTOPUS.palette[ch]);
  });
  it('sw mirrors se, nw mirrors ne', () => {
    const a = poseFrame(OCTOPUS, 'se', 'stand', 0), b = poseFrame(OCTOPUS, 'sw', 'stand', 0);
    for (let y = 0; y < 26; y++) for (let x = 0; x < 26; x++) expect(at(b, x, y)).toBe(at(a, 25 - x, y));
  });
  it('walk frames differ and come back every 4 ticks', () => {
    const f = (t: number) => JSON.stringify(poseFrame(OCTOPUS, 'se', 'walk', t).px);
    expect(f(0)).not.toBe(f(1)); expect(f(0)).toBe(f(4));
  });
  it('sit has nothing below the legs row', () => {
    const f = poseFrame(OCTOPUS, 'se', 'sit', 0);
    for (let y = OCTOPUS.rig.legs + 1; y < 26; y++) for (let x = 0; x < 26; x++) expect(at(f, x, y)).toBeNull();
  });
  it('eat puts a bowl at the first hand', () => {
    const [hx, hy] = OCTOPUS.rig.hands[0];
    expect(poseFrame(OCTOPUS, 'se', 'eat', 0).px).toContain('#f2efe6');
    void hx; void hy;
```

规则（照设计 §2）：新 agent（快照里出现、`state` 不是终态）→ actor 从门口 `arrive`；步行速度 4 格 / 秒，按 `path` 逐格；`work` 条件：`state === 'running'` 且（`beats` 最后一个在 20 s 内，或 `startedAt` 在 20 s 内）；`idle` → 用 `seed + t` 的 PRNG（mulberry32）挑活动：eat / drink / smoke / toilet / power / chat / game / stand，持续 5–20 s；`game` 在自己座位上（screen `game`）；`work` 条件成立时立刻放下活动走回座位；终态 → `toCheckout` → `checkout`（2 s，生成 `Receipt`，进 `receipts` 头部，最多 50）→ `leave` → 到门口 `gone`；`failed` 先 2 s `bsod`；快照里消失 → `wait`，30 s 后直接 `gone`（不结账）；`reduced` 时移动瞬间完成（path 走完）。网管：`mainBusy` → 前台敲键盘，否则每 20–40 s 随机巡场（走到某个空座位旁站 3 s 再回来）；结账时网管面向收银台；随机喊话（60–120 s 一次，从固定的 6 句里挑，包括「NN 号机还有 5 分钟」用一个在场 actor 的座位号）。
